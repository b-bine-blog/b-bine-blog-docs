# D-141 글 공유 버튼을 공유할 곳을 고르는 메뉴로 바꾼다

- 날짜: 2026-10-19
- 관련 항목: BRD-07, 정책 6.2, D-66, D-100 #5, FR-047
- 상태: 확정

## 결정
1. 글 상세의 "링크 복사" 버튼을 "공유" 버튼으로 바꾼다. 누르면 공유할 곳을 고르는 메뉴가 열린다.
2. 메뉴 항목은 아래와 같다.

| 항목 | 동작 | 보이는 조건 |
|---|---|---|
| 링크 복사 | 글 주소를 클립보드에 복사 | 늘 |
| 카카오톡 | 카카오 SDK로 공유(미리보기는 og 태그) | 카카오 JavaScript 키가 있을 때 |
| X(트위터) | 공유 창을 새 창으로 | 늘 |
| 페이스북 | 공유 창을 새 창으로 | 늘 |
| 텔레그램 | 공유 창을 새 창으로 | 늘 |
| 다른 앱 | 기기 공유 시트(인스타그램 등) | 브라우저가 지원할 때 |

3. 공유하는 주소는 지금 링크 복사와 같다. 일부 공개 블로그 글은 공유 값을 붙이고, 비공개·공지 글은 버튼이 없다(D-100 #5).
4. 메뉴 밖을 누르거나 Esc를 누르면 닫힌다.
5. 카카오 키는 설정값으로 둔다. 비어 있으면 카카오톡 항목만 숨는다.

#### 설정값
```
share.kakao-js-key=${KAKAO_JS_KEY:}
```

주의: 인스타그램은 웹 공유 주소가 없어 "다른 앱"(휴대폰 공유 시트)으로만 보낸다.

## 이유
정책 6.2 2단계(SNS 공유)를 채우기 위해서다. 공유할 곳을 사용자가 고르게 한다(2026-10-19 사용자).

## 이전 내용 → 바꾼 이유
- 1단계는 "링크 복사" 버튼 하나였다 → 메뉴로 바꾸고 SNS 항목을 더했다.
- DB 변경은 없다.
