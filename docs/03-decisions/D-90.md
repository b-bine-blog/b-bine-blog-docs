# D-90 관리자 계정은 블로그 활동(만들기·참여·글쓰기·댓글·좋아요·팔로우)을 하지 않음

- 날짜: 2026-10-06
- 관련 항목: 2장, SEC-09
- 상태: 확정

## 결정
관리자 계정은 블로그 활동(만들기·참여·글쓰기·댓글·좋아요·팔로우)을 하지 않음 (2장, SEC-09)

## 이유
관리자는 블로그를 관리하는 역할이라 활동과 관리를 나눔. 같은 users 테이블에서 role = ADMIN으로 구분하므로 별도 관리자 테이블은 두지 않음

## 이전 내용 → 바꾼 이유
2장 권한표에서 관리자도 블로그 생성·참여·글쓰기·팔로우가 O였음 → X로 변경(글쓰기는 메인 공지만)

## 추가 (2026-10-07)
2장 권한 표의 메인 관리자 열에서 블로그 생성·참여 신청·글쓰기·팔로우·댓글·좋아요를 X로 고치고, "참여 승인·멤버 강퇴"도 ADM-01·D-44에 맞춰 X로 고친다 (박민수 님 확인).
