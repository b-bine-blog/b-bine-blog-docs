# D-68 블로그 개수 제한값은 설정 파일에 두고 환경변수로 덮어씀

- 날짜: 2026-10-06
- 관련 항목: 7장 개수 제한값, BLG-10
- 상태: 확정

## 결정
블로그 개수 제한값은 설정 파일에 두고 환경변수로 덮어씀. 만들 때는 개수 확인과 생성을 DB에서 잠금 (7장 개수 제한값, BLG-10)

## 이유
개수를 자주 바꿀 일이 없어 설정 파일이면 충분함. 환경변수로 두면 서버가 여러 대여도 한 곳에서 같은 값을 적용할 수 있음. 동시에 두 번 누르면 두 요청이 모두 개수 확인을 통과해 제한을 넘을 수 있어 DB 잠금으로 막음

## 이전 내용 → 바꾼 이유
추천안 "설정 파일"에 이중화 대비(환경변수)와 동시 생성 방지(DB 잠금)를 더해 확정
