# D-99 인증번호 발송에 IP별 요청 제한은 두지 않음

- 날짜: 2026-10-08
- 관련 항목: USR-02, USR-06, SCL-01, D-80, D-97
- 상태: 확정

## 결정
가입 인증번호 발송(`POST /api/auth/signup/email-code`)과 비밀번호 재설정 인증번호 발송(`POST /api/auth/password-reset/code`)에는 지금은 IP별 요청 제한을 두지 않는다. 같은 주소로는 1분에 한 번만 보내는 제한(USR-02, D-97)만 둔다.

## 이유
사용자 결정(2026-10-08). 한 IP가 여러 주소로 메일을 보내는 악용은 막지 못하므로, 필요해지면 로그인·이메일 찾기처럼 설정값으로 된 IP 제한을 더한다.

## 이전 내용 → 바꾼 이유
원본은 IP 제한을 로그인(D-80)과 이메일 찾기(USR-08)에만 두고 발송 API에는 언급이 없었다. 001 구현 점검 중 이 빈 곳을 확인해 "지금은 두지 않음"으로 정했다.
