# D-132 카테고리 없는 글은 "잡담", 글 목록 제목 위에 카테고리와 그림 표시

- 날짜: 2026-10-14
- 관련 항목: BRD-02, D-100 #8
- 상태: 확정

## 결정
1. 카테고리 없이 쓴 글의 이름을 "미분류"에서 "잡담"으로 바꾼다. 화면에 보이는 이름만 바뀌고, 저장 방식(카테고리 없음)과 규칙(카테고리를 지우면 그 글은 카테고리 없음으로)은 D-100 #8 그대로다.
2. 글 목록(메인 피드, 블로그 홈, 검색, 태그, 공지사항)에서 제목 위에 카테고리를 작게 보여 준다. 카테고리가 없으면 "잡담"이다.
3. 글 본문에 그림이 있으면 카테고리 옆에 작은 그림 표시를 붙인다(본문의 첫 그림으로 판단).
4. 아래 줄(블로그·작성자·시각)에 있던 카테고리는 위로 옮긴다. 메인 위에 고정된 공지에는 카테고리 줄을 두지 않는다.

## 이유
글이 어디서 어떻게 쓰였는지 사용자가 글에 들어가지 않아도 목록에서 쉽게 알아볼 수 있게 하려고(2026-10-14 사용자).

## 이전 내용 → 바꾼 이유

- 글 목록: 카테고리를 아래 줄에 글자로만 → 제목 위에 따로, 그림 표시와 함께.
