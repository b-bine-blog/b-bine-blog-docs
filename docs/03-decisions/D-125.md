# D-125 소셜 로그인(구글·카카오·네이버)을 넣는다

- 날짜: 2026-10-13
- 관련 항목: USR-09(신설), 001-member-auth, D-28, D-53, D-80, D-10
- 상태: 확정

## 결정
1. 구글·카카오·네이버 소셜 로그인을 넣는다. 명세는 `specs/008-social-login/spec.md`.
2. 처음 가입하면 이메일 인증번호·비밀번호 단계 없이 가입 ③단계(이름·닉네임·전화번호·필수 동의 2개)만 받는다.
3. 같은 이메일로 이미 가입한 회원이 있으면 새 계정을 만들지 않고, 기존 비밀번호를 한 번 확인한 뒤 연결한다.
4. 소셜 서비스가 확인된 이메일을 주지 않으면(비즈 앱이 아닌 카카오) 처음 가입 때만 이메일을 직접 입력받아 6자리 인증번호로 확인한다.
5. 소셜로만 가입한 회원은 비밀번호가 없고, "비밀번호 찾기"로 만들 수 있다.

## 이유
과제 항목 "OAuth2 소셜 로그인"(2026-10-13 사용자 요청). 서비스는 사용자가 결정 카드에서 "구글+카카오"를 고른 뒤 "네이버 로그인도 만들어야 해"라고 더했다. 3번과 4번은 사용자가 확인 질문에서 1번(추천안)을 골랐다.
