# D-124 main에 합치면 버전 태그를 자동으로 단다

- 날짜: 2026-10-13
- 관련 항목: D-123(Git Flow), D-106(GitHub Actions 배포)
- 상태: 확정

## 결정
1. `main`에 push되면 태그 워크플로(`.github/workflows/tag.yml`)가 `layout.js`의 `SITE_VERSION`(예: `v1.11`)으로 태그를 단다.
2. 같은 이름의 태그가 이미 있으면 건너뛴다. 버전을 올리지 않은 합치기(릴리스 노트만 더한 두 번째 합치기 등)는 새 태그를 만들지 않는다.
3. 급한 수정(hotfix)은 버전 표시를 `vX.YY.Z`로 올려야 태그가 달린다.
4. 머리 커밋에 `[skip ci]`가 있으면 태그도 달리지 않는다. 그때는 GitHub의 Releases에서 직접 만들거나 tag 워크플로를 직접 실행한다.
5. 첫 태그 `v1.10`은 2026-10-13 사용자가 GitHub Releases에서 직접 만들었다.

## 이유
작업 환경(Claude Code)에서 태그 올리기가 막혀 있어 v1.10 태그를 사용자가 직접 만들어야 했다. 사용자가 "앞으로 내가 올려야 하는 거야?"라고 물었고, 자동화를 골랐다(2026-10-13).
