# D-26 이메일 찾기 결과에서 비밀번호 재설정까지 이어짐

- 날짜: 2026-10-02
- 관련 항목: USR-08
- 상태: 확정

## 결정
이메일 찾기 결과에서 비밀번호 재설정까지 이어짐. 재설정 요청은 임시 토큰(10분)으로 함 (USR-08)

## 이유
이메일과 비밀번호를 모두 잊어도 한 흐름으로 해결됨. 바꾸기 직전에 이메일 인증을 거치므로 이름·전화번호만 아는 사람은 바꿀 수 없음. 회원 번호를 넘기면 번호만 바꿔 남에게 인증 메일을 보낼 수 있어 토큰을 씀
