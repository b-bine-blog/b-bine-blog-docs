# D-138 본문 속 우리 블로그 글 주소를 글 카드로 보여 준다

- 날짜: 2026-10-15
- 관련 항목: BRD-01, SEC-06, D-64
- 상태: 확정

## 결정
1. 글 본문에서 한 줄이 우리 블로그 글 주소만으로 되어 있으면 그 글의 카드로 바꿔 보여 준다.
2. 카드에는 블로그 이름, 제목, 작성자, 작성 시각, 좋아요·댓글 수, 대표 그림이 있다. 누르면 그 글로 간다.
3. 그 글을 볼 수 없는 사람(비공개 블로그 등)에게는 카드 없이 주소 링크만 보인다.
4. 카드를 띄워도 그 글의 조회수는 오르지 않는다.
5. 카드의 글자는 모두 textContent로 넣는다(D-64).

#### API
```
GET /api/posts/{postId}/card
```

## 이유
사이트에 관련 내용을 공유할 때 도움이 되기 때문이다(2026-10-15 사용자).

## 이전 내용 → 바꾼 이유
- 본문에 붙여 넣은 글 주소는 그냥 글자로 보였다 → 그 글의 카드로 보이고 누르면 이동한다.
- DB 변경은 없다.
