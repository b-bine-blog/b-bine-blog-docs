# D-116 메인 위쪽 띠에 최신 공지·인기 블로그·인기 글을 번갈아 보여 준다

- 날짜: 2026-10-13
- 관련 항목: D-115(메인 블로그 카드), D-109(공지 고정), D-89(인기순)
- 상태: 일부 변경됨 → D-117(소개 문구를 빼고 소식 띠를 맨 위로)

## 결정
1. 메인 위쪽 초록 띠의 소개 문구 아래에 소식 한 줄을 두고, 최신 공지 → 인기 블로그 → 인기 글을 5초마다 번갈아 보여 준다.
2. 각각 기존 API의 첫 항목을 쓴다: `/api/notices`, `/api/blogs?sort=popular`, `/api/feed?tab=POPULAR`. 새 API는 없다.
3. 아래 점을 눌러 고를 수 있고, 마우스를 올리거나 키보드로 고르는 동안은 멈춘다. 불러오지 못한 항목은 빼고, 모두 실패하면 띠를 예전처럼 둔다.

## 이유
사용자가 2026-10-13에 "이 부분에 최신 공지사항, 인기 블로그, 인기 글을 번갈아 가면서 띄웠으면 좋겠다"고 요청함.
