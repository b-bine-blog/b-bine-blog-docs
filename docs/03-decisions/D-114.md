# D-114 운영 규칙 화면을 두고 숫자는 설정값으로 채운다

- 날짜: 2026-10-13
- 관련 항목: 4.5(데이터 보관·삭제), D-68(숫자는 설정값), specs/007-site-rules
- 상태: 확정

## 결정
1. 화면 아래 "개인정보 처리방침" 옆에 "운영 규칙"(`/rules.html`)을 둔다. 로그인 없이 본다.
2. 삭제와 보관, 블로그 폐쇄, 블로그 만들기와 참여, 글과 댓글, 로그인과 계정 보안, 신고와 제재, 시스템 문의를 다룬다.
3. 숫자는 화면에 적지 않고 `GET /api/site-rules`가 실제 설정값을 내려 준다. 설정을 바꾸면 안내도 같이 바뀐다.
4. 비밀 값과 내부 운영값(요청 제한 창, 관리자 조회 한도 등)은 내려 주지 않는다. DB는 바뀌지 않는다.

## 이유
사용자가 2026-10-13에 "개인정보 처리방침 쪽에 시스템 주요 규칙(언제 삭제되는지, 주의사항 등)이 적힌 칸이 있었으면 좋겠다"고 요청함.
화면에 숫자를 직접 적으면 설정을 바꿀 때 안내가 틀려지므로 설정값을 그대로 쓴다(D-68).
