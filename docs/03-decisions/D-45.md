# D-45 블로그 안의 신고는 블로그장이, 블로그·블로그장에 대한 신고는 메인 관리자가 처리

- 날짜: 2026-10-02
- 관련 항목: SOC-06, ADM-04, BLG-13
- 상태: 확정

## 결정
블로그 안의 신고는 블로그장이, 블로그·블로그장에 대한 신고는 메인 관리자가 처리 (SOC-06, ADM-04, BLG-13)

## 이유
신고 처리 결과(경고·정지·강제 퇴장)는 메인 관리자와 블로그장 모두에게 필요한 권한이므로, 각자 자기 범위의 신고를 처리함
