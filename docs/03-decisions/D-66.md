# D-66 화면은 정적 HTML + JS(화면과 API를 나눠 개발)

- 날짜: 2026-10-06
- 관련 항목: 7장 화면 방식, SEC-10
- 상태: 확정

## 결정
화면은 정적 HTML + JS(화면과 API를 나눠 개발). 글 상세는 SNS 미리보기를 위해 서버가 og 태그만 채움 (7장 화면 방식, SEC-10)

## 이유
화면과 서버(API)를 나눠 개발할 수 있고 팀이 익숙한 방식 (팀 확인 필요). 글 본문은 서버가 걸러서 보내므로 XSS 방어(D-64)는 그대로 유지됨

## 이전 내용 → 바꾼 이유
전부 Thymeleaf(D-63) → 팀 논의 후 HTML + JS로 변경
