# D-53 로그인은 JWT로 하고 토큰은 HttpOnly 쿠키에 담음

- 날짜: 2026-10-06
- 관련 항목: SEC-04, 4.1 아래 팀 결정
- 상태: 확정

## 결정
로그인은 JWT로 하고 토큰은 HttpOnly 쿠키에 담음 (SEC-04, 4.1 아래 팀 결정)

## 이유
서버 이중화를 대비해 서버끼리 로그인 정보를 공유하지 않아도 되게 함. HttpOnly 쿠키라 JS가 토큰을 읽을 수 없어 XSS 탈취를 막음

## 이전 내용 → 바꾼 이유
세션 + 쿠키(D-11) → 이중화 때 Spring Session + Redis가 필요해서, 미리 대비하기 위해 변경
