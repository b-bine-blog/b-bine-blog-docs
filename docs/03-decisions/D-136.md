# D-136 블로그 화면에 그 블로그 글만 찾는 검색칸을 둔다

- 날짜: 2026-10-14
- 관련 항목: BRD-08, FR-017~FR-021, FR-052~FR-058
- 상태: 확정

## 결정
1. 블로그 화면의 "글" 제목 바로 옆에 검색칸을 둔다.
2. 그 블로그의 글만 찾는다. 검색 대상은 글 제목, 태그, 작성자 닉네임이다.
3. 찾는 방식과 검색어 규칙(2~20자, 글자·숫자 하나 이상)은 통합 검색(BRD-08)과 같다.
4. 카테고리를 골라 둔 상태면 그 카테고리 안에서 찾는다. 결과는 최신순 번호 페이지다.
5. 블로그 열람 규칙을 그대로 따른다. 비공개 블로그는 멤버만 찾을 수 있다.
6. 최근 검색어에는 남기지 않는다.
7. 검색칸을 비우면 전체 글 목록으로 돌아간다.

#### API
```
GET /api/blogs/{blogId}/posts?q=검색어
```

## 이유
블로그에 글이 많아지면 위쪽 통합 검색보다 블로그 안에 따로 검색칸을 두는 편이 사용자 입장에서 편하기 때문이다(2026-10-14 사용자).

## 이전 내용 → 바꾼 이유
- BRD-08 통합 검색: "메인 전용" → 메인 통합 검색은 그대로 두고, 블로그 화면에 그 블로그 글만 찾는 검색칸을 더함.
- DB 변경은 없다. 기존 posts 제목 FULLTEXT 인덱스를 쓴다.
