# D-102 소셜·알림 세부 규칙 확정 (003 확인 항목)

- 날짜: 2026-10-08
- 관련 항목: SOC-01~06, 2장 권한표·역할표, 3.2, 3.6, 4.4, 4.5, 6.5, 6.7, D-22, D-36, D-37, D-60, D-62, D-72, D-76, D-98, D-100
- 상태: 확정

## 결정
003 명세의 확인 필요 항목을 29개 질문으로 묶어 아래처럼 정한다. 숫자는 설정값으로 둔다(D-68).

| # | 질문 | 결정 |
|---|---|---|
| 1 | 자기 자신을 팔로우하거나, 자기 블로그를 구독하거나, 자기 글·댓글을 신고할 수 있나요? 내 글에 내가 단 댓글, 내 댓글에 내가 단 대댓글, 내 글에 내가 누른 좋아요는 알림이 가나요? | 자기 자신 팔로우, 블로그장의 자기 블로그 구독, 자기 글·댓글·블로그 신고는 모두 막음(서버에서 거부). 내 행동은 나에게 알리지 않음(D-100 13번과 같음) |
| 2 | 비공개 블로그를 새로 구독할 수 있나요? | 멤버가 아니면 구독할 수 없음(비공개는 멤버만 보므로). 그 블로그의 멤버는 구독할 수 있음 |
| 3 | 팔로우를 취소했다가 다시 하면 새 팔로워 알림이 또 가나요? 구독도 같나요? | 같은 사람이 같은 대상에게 다시 팔로우·구독하면 알림을 다시 보내지 않음(좋아요와 같음, D-100 13번) |
| 4 | 팔로우·구독을 빠르게 반복해 누를 때 요청 제한은 몇 번까지인가요? | 회원 한 명당 팔로우·구독 각각 1분에 30번(좋아요와 같은 값, D-100 12번, 설정값). 넘으면 잠시 뒤 다시 하라고 안내 |
| 5 | 블로그가 폐쇄되면 그 블로그 구독은 어떻게 되나요? 내 구독 목록에는 어떻게 보이나요? | 폐쇄 예정 7일 동안은 그대로 두고(D-67), 폐쇄되는 순간 구독을 지워 목록에서 사라지게 함. 구독자는 이미 폐쇄 예정 알림을 받았으므로 따로 알리지 않음 |
| 6 | 프로필의 "운영하는 블로그", "참여한 블로그"에 일부 공개·비공개 블로그도 보여 주나요? | 다른 사람이 볼 때는 공개 블로그만 보여 주고 일부 공개·비공개는 아예 뺌(이름도 안 보임, 검색에서 비공개를 아예 뺀 것과 같음, D-100 16번). 본인이 볼 때는 모두 보여 줌 |
| 7 | 프로필 소개는 몇 자까지, 어떤 글자로 쓸 수 있나요? | 0~500자(선택, 설정값, 블로그 소개와 같음, D-98). 글자 종류는 제한하지 않고 줄바꿈 허용. 화면에는 textContent로 넣음(D-64) |
| 8 | 비회원도 다른 회원의 프로필과 팔로워 수를 볼 수 있나요? | 볼 수 있음. 닉네임·사진·소개·공개 블로그·팔로워 수만 있어 개인정보가 없음(4.4). 팔로우 버튼만 로그인 회원에게 보임 |
| 9 | 팔로워·팔로잉 목록은 누가 볼 수 있고, 한 페이지에 몇 명씩 보여 주나요? | 프로필을 볼 수 있는 사람 누구나(8번과 같게). 닉네임·사진만(4.4). 최근에 팔로우한 순서로 20명씩 번호 페이지(D-76, 설정값) |
| 10 | 차단을 해제할 수 있나요? 내가 차단한 사람 목록을 볼 수 있나요? | 내 정보 > 차단 목록에서 닉네임·차단한 날짜를 보고 해제할 수 있음. 해제해도 차단 때 끊긴 팔로우는 되살리지 않음 |
| 11 | 차단당한 사람 쪽에서는 어떻게 되나요? 차단한 사람의 글이 숨겨지나요? 차단 중 다시 팔로우할 수 있나요? 차단당한 사람의 댓글·좋아요·팔로우가 알림을 만드나요? 차단당한 줄 알 수 있나요? | 숨기는 것은 차단한 사람 쪽만(지금 004 구현과 같음). 차단이 있는 동안은 두 사람 모두 서로 팔로우할 수 없음. 차단당한 사람의 행동은 차단한 사람에게 알림을 만들지 않음. 차단 사실은 알림·화면 어디에도 알리지 않음 |
| 12 | 블로그장이 차단한 회원의 참여 신청을 자동 거절할 때 거절 알림을 보내나요? "거절되면 7일 뒤 재신청" 규칙도 적용하나요? 부블로그장이 차단한 회원도 자동 거절하나요? | 일반 거절과 똑같이 처리: 거절 알림을 보내고 7일 규칙도 적용(차단 사실은 드러내지 않음, D-98 12번, 지금 구현과 같음). 자동 거절은 블로그장의 차단만 기준(SOC-05 문구대로). 부블로그장의 차단은 개인 차단으로만 적용 |
| 13 | 블로그장이 차단하기 전에 이미 들어와 있던 그 회원의 참여 신청도 자동 거절하나요? | 자동 거절함. 12번과 같이 일반 거절 알림만 보냄 |
| 14 | 신고할 때 고를 수 있는 사유는 무엇이고, 직접 입력 칸이 있나요? | 스팸·광고, 욕설·비방, 음란·불쾌한 내용, 개인정보 노출, 저작권 침해, 기타 6가지(목록은 설정값). 모든 사유에 추가 설명(선택, 최대 500자)을 받고, "기타"는 설명 필수 |
| 15 | 신고당한 사람이나 처리하는 블로그장에게 신고한 사람의 닉네임을 보여 주나요? | 신고당한 사람에게는 신고 사실도 신고자도 알리지 않음. 처리하는 블로그장에게도 신고자를 보여 주지 않음(보복 방지, 지금 구현과 같음). 메인 관리자만 허위 신고 확인을 위해 신고자를 볼 수 있음 |
| 16 | 회원이 탈퇴하면 그 회원의 팔로우·팔로워·구독·차단 관계와 그 회원이 한 신고는 어떻게 되나요? | 팔로우·팔로워·구독·차단 관계는 탈퇴 즉시 지움(화면에 안 보이고 재가입해도 이어지지 않으므로 30일 보관할 필요 없음). 그 회원이 한 신고는 운영 기록이라 1년 보관(D-60)하고 신고자는 "탈퇴한 회원"으로 표시 |
| 17 | 알림 목록은 어떤 순서로, 한 번에 몇 개씩 보여 주나요? | 최신순, 20개씩, 아래 "더 보기" 버튼(피드와 같음, D-100 18번, 설정값) |
| 18 | 알림은 언제 읽음이 되나요? "모두 읽음" 버튼이 있나요? | 알림 하나를 누르면 그 알림이 읽음. 사이드바나 탭을 여는 것만으로는 읽음이 되지 않음. 보고 있는 탭의 알림을 모두 읽음으로 바꾸는 "모두 읽음" 버튼을 둠 |
| 19 | 전체 삭제는 모든 탭의 알림을 지우나요, 보고 있는 탭만 지우나요? 하나씩 지울 수도 있나요? | "전체" 탭에서 누르면 모두, 다른 탭에서 누르면 그 탭 알림만 지움(지우기 전 확인 창). 알림마다 x 버튼으로 하나씩도 지울 수 있음 |
| 20 | 종 아이콘에 안 읽은 알림 개수를 보여 주나요? | 보여 줌. 숫자로 표시하고 99개가 넘으면 "99+". 30초 확인(D-72)은 개수만 받아 가볍게 하고, 로그인 연장 활동으로 세지 않음(D-62) |
| 21 | 알림을 누르면 어디로 가나요? | 댓글·대댓글·좋아요·공지 → 그 글. 새 팔로워 → 그 회원 프로필. 블로그 구독·폐쇄 예정·철회·비공개 전환 → 그 블로그. 참여 신청 → 블로그 관리의 신청 목록. 위임 요청 → 수락·거절 화면. 내 글 삭제됨·경고·정지 등 운영 알림과 참여 결과 → 이동 없이 내용만 보여 줌. 이동한 곳의 권한은 서버가 다시 확인하고, 볼 수 없게 된 곳이면 "볼 수 없는 내용입니다" 안내 |
| 22 | 폐쇄 3일 전·1일 전 알림은 폐쇄 버튼을 누른 때의 멤버·구독자에게 보내나요, 알림을 보내는 그 시각의 멤버·구독자에게 보내나요? | 보내는 그 시각의 멤버·구독자(지금 구현과 같음). 그 사이 떠난 사람은 받지 않고, 새로 들어온 사람은 받음. 한 사람에게 같은 알림은 한 번만 |
| 23 | 서버가 꺼져 있던 날의 3일 전·1일 전 알림은 다음 배치 때 보내나요? | 이미 정해짐: 다음 실행 때 밀린 것까지 보내고 보낸 기록으로 두 번 보내지 않음(3.2 폐쇄 처리, D-98 13번). 확인만 부탁드립니다 |
| 24 | 대기 중인 위임 요청이 폐쇄 버튼 때문에 자동 취소되면, 요청을 받은 멤버에게 취소 알림을 보내나요? | 따로 보내지 않음. 그 멤버도 같은 때 폐쇄 예정 알림을 받고, 수락·거절 버튼은 사라짐(지금 구현과 같음) |
| 25 | 비공개 전환 알림은 멤버이면서 구독자인 회원도 받나요? 일부 공개로 바뀔 때도 알림을 보내나요? | 구독자 모두에게 보냄(3.6 표 "구독자", 지금 구현과 같음). 바꾼 본인은 빼고, 한 사람에게 한 번만. 일부 공개로 바뀔 때는 구독자가 계속 볼 수 있으므로 알림 없음(D-98 17번) |
| 26 | 처음 가입했을 때 끌 수 있는 알림 9가지의 체크박스는 켜져 있나요? | 모두 켜짐(공지사항 포함). 회원이 내 정보에서 끔 |
| 27 | 알림 보관 기간을 30일에서 7일로 줄이면, 이미 7일이 지난 알림도 바로 지우나요? | 다음 04:00 정리 때 받은 지 7일 지난 알림을 모두 지움(이미 받은 것 포함). 줄이기 전에 "7일이 지난 알림은 다음 정리 때 지워집니다"라고 안내. 다시 30일로 늘려도 지운 알림은 돌아오지 않음 |
| 28 | 회원이 직접 지운 알림도 30일 보관하나요? | 보관하지 않고 바로 지움. 30일 보관(4.5)은 글·댓글·사진에 대한 규칙이고, 알림은 본인만 보는 안내라 되살릴 일이 없음 |
| 29 | 블로그장의 "블로그 알림 보관 설정(7일 또는 일괄 삭제)"은 회원 개인 설정과 따로 블로그 단위로 두나요? | 따로 두지 않음. 알림은 받는 사람 한 명의 것이라, 블로그장도 내 정보의 개인 설정(7일·일괄 삭제)을 그대로 씀. 2장 블로그장 표와 6.7의 "회원, 블로그장"은 둘 다 같은 개인 설정을 쓴다는 뜻으로 읽음 |
