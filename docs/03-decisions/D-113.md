# D-113 다크 모드를 두고 상단 메뉴 버튼으로 바꾼다

- 날짜: 2026-10-12
- 관련 항목: D-107(초록 디자인)
- 상태: 확정

## 결정
1. 모든 화면에 어두운 화면(다크 모드)을 둔다. 상단 메뉴 오른쪽 해·달 버튼으로 바꾼다.
2. 고른 값은 그 브라우저에만 저장한다(localStorage `mb.theme`). 고른 적이 없으면 기기 설정(prefers-color-scheme)을 따른다.
3. 색은 같은 초록 계열을 어둡게 맞춘다. 글쓰기 에디터(Toast UI) 상자 안은 밝게 둔다.
4. 회원 정보에 저장하지 않으므로 DB는 바뀌지 않는다.

## 이유
사용자가 2026-10-12에 "다크모드 좀 따로 설정해 줄래"라고 요청함. 로그인하지 않아도 쓸 수 있게 브라우저 저장으로 정했다.
