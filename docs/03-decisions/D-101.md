# D-101 CSP에서 인라인 스타일 허용 (Toast UI 에디터)

- 날짜: 2026-10-08
- 관련 항목: SEC-12, BRD-02, D-64, D-74, 004 research R-02
- 상태: 확정

## 결정
보안 헤더 CSP에 `style-src 'self' 'unsafe-inline'`을 더한다. 스크립트(`script-src`)는 그대로 `'self'`와 Turnstile만 허용한다.

## 이유
- Toast UI Editor(D-74)는 툴바 팝업 위치·크기를 요소의 style 속성으로 정한다. CSP가 인라인 스타일을 막으면 화면 콘솔에 오류가 수십 개 나고 툴바 팝업이 엉뚱한 곳에 그려진다(2026-10-08 Playwright로 360px·PC 확인).
- 인라인 스타일로 할 수 있는 공격은 화면을 가리는 정도이고 스크립트 실행은 안 된다. 글 본문은 서버에서 jsoup으로 거르며 style 속성을 허용하지 않으므로(D-64) 회원이 넣은 스타일은 남지 않는다.

## 이전 내용 → 바꾼 이유
`default-src 'self'`가 스타일에도 적용돼 인라인 스타일이 막혀 있었음 → 에디터가 정상으로 그려지도록 스타일만 허용
