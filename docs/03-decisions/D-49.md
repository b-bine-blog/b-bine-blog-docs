# D-49 블로그 공개 범위를 공개·일부 공개·비공개 3단계로

- 날짜: 2026-10-06
- 관련 항목: BLG-01
- 상태: 확정

## 결정
블로그 공개 범위를 공개·일부 공개·비공개 3단계로. 일부 공개는 공유 링크로만 들어감, 비공개는 링크 없이 멤버만 (BLG-01)

## 이유
멤버가 아닌 사람에게 링크로 보여주는 기능과 진짜 비공개를 둘 다 제공함. 블로그 주소는 추측할 수 있어서 공유 링크에는 무작위 값을 넣음

## 이전 내용 → 바꾼 이유
공개·비공개 2단계, 6.2에 "URL을 주면 보이게"와 "권한 없는 사람은 못 봄"이 충돌 → 3단계로 나눠 해결 (당시 비공개 범위 추천안 채택)
