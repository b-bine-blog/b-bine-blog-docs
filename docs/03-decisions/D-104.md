# D-104 관리자 강제 폐쇄는 관리자만 철회

- 날짜: 2026-10-08
- 관련 항목: ADM-02, BLG-09
- 상태: 확정

## 결정
메인 관리자가 강제 폐쇄한 블로그(폐쇄 사유가 관리자 폐쇄인 것)는 블로그장이 철회할 수 없다. 관리자 폐쇄는 메인 관리자만 되돌릴 수 있다. 이미 폐쇄 예정인 블로그에 관리자가 "블로그 폐쇄"를 골라 사유가 관리자 폐쇄로 바뀐 경우(D-103 #8)도 같다.
블로그장이 직접 폐쇄한 블로그의 철회는 그대로 블로그장만 한다(BLG-09). 관리자는 관리자 폐쇄만 철회할 수 있고, 블로그장 폐쇄·권한 박탈 폐쇄는 철회하지 않는다.
관리자가 철회하면 블로그장 철회와 같이 운영 중으로 돌아가고, 블로그장을 뺀 멤버·구독자에게 철회 알림이 가며, 관리자 활동 기록에 남는다 (ADM-02, ADM-06)

## 이유
관리자 조치를 당사자가 바로 되돌리면 강제 폐쇄의 의미가 없어짐. 2026-10-08 사용자 결정
