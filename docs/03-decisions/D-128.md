# D-128 작업 브랜치에 올리면 GitHub Actions가 전체 테스트를 돌린다

- 날짜: 2026-10-14
- 관련 항목: D-123(Git Flow), D-106·D-127(배포)
- 상태: 확정

## 결정
1. `.github/workflows/ci.yml`: `develop`, `feature/**`, `release/**`, `hotfix/**`에 push하거나 `develop`·`main`으로 PR을 만들면 `./gradlew test`(전체 통합 테스트, Testcontainers MySQL 8.0)를 돌린다.
2. 문서·릴리스 노트만 바꾼 push(`docs/**`, `release-notes/**`, `*.md`)는 건너뛴다. 같은 브랜치에 새로 push하면 이전 실행은 멈춘다.
3. 실패하면 테스트 보고서(`build/reports/tests/test`)를 Actions 실행 화면에 7일 동안 올린다.
4. `main` 배포(deploy.yml)는 테스트를 다시 돌리지 않는다. `main`에는 이 검사를 거친 `develop`·`release`만 합친다.

## 이유
과제 항목 "GitHub Actions 기반 CI/CD 구성"에서 CI(자동 테스트)를 더하기로 사용자가 정했다(2026-10-14). 그전에는 테스트를 Claude 작업 환경에서만 돌렸다.
