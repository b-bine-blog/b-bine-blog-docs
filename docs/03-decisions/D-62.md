# D-62 로그인 30분 연장 기준: 직접 한 행동으로 간 요청만 활동으로 셈

- 날짜: 2026-10-06
- 관련 항목: SEC-04
- 상태: 확정

## 결정
로그인 30분 연장 기준: 직접 한 행동으로 간 요청만 활동으로 셈. 알림 자동 확인·스크롤은 제외, 글쓰기 중 입력은 연장, 만료 5분 전 연장 안내 (SEC-04)

## 이유
알림 자동 확인까지 세면 탭만 열어 두어도 로그아웃되지 않아 "나가면 로그아웃"이 의미가 없어짐. 글을 오래 쓰는 중에는 서버 요청이 없어 저장하는 순간 로그아웃될 수 있어 입력 중 연장과 만료 전 안내를 둠
