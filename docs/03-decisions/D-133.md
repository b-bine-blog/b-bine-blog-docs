# D-133 고친 글은 글 목록에 "수정됨" 표시

- 날짜: 2026-10-14
- 관련 항목: BRD-02, REQ-040, D-132
- 상태: 확정

## 결정
1. 글을 수정하면 posts.edited_at에 고친 일시를 기록한다. 고친 적이 없으면 NULL이다.
2. 글 목록에서 제목 위 카테고리 줄(D-132)에 "수정됨"을 붙인다. 그림 표시가 있으면 그 뒤에 붙인다.
3. 조회수·좋아요가 늘어도 고친 것으로 보지 않는다. 그래서 updated_at이 아닌 새 칸(edited_at)을 둔다.
4. 이 칸이 생기기 전에 고친 글은 기록이 없어 표시되지 않는다.

## 이유
"수정됨" 표시가 없으면 악용할 수 있기 때문이다. 예를 들어 이상한 글을 올렸다가 댓글이 달리자마자 다른 글로 고쳐 버리는 경우다(2026-10-14 사용자).

## 이전 내용 → 바꾼 이유
- 글 목록: 고쳤는지 알 수 없음 → 카테고리 줄에 "수정됨" 표시.
- posts: 수정 일시(updated_at)만 있음 → 조회수·좋아요에도 바뀌어 고친 일시로 쓸 수 없어 edited_at을 더함(Crowfoot 문서 버전 56).
