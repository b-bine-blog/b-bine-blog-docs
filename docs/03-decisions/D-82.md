# D-82 Refresh Token은 DB(MySQL)에 저장한다

- 날짜: 2026-10-06
- 관련 항목: SEC-04, USR-04, 4.3 로그인 토큰 저장
- 상태: 확정

## 결정
Refresh Token은 DB(MySQL)에 저장한다 (SEC-04, USR-04, 4.3 로그인 토큰 저장)

## 이유
이미 쓰는 DB라 추가 비용이 없고, 서버를 늘려도 모든 서버가 같은 DB를 보므로 바꿀 것이 없음. 토큰을 새로 받을 때만 DB를 읽어 부담이 작음. Redis는 서버 1대인 1차에도 따로 띄워야 하고, 저장하지 않으면 로그아웃해도 토큰을 폐기할 수 없어 제외

## 이전 내용 → 바꾼 이유
"DB나 Redis"로 미정 → 팀이 DB로 확정. 4.3의 세션 공유 비교표는 JWT 채택(D-53)으로 필요 없어져 로그인 토큰 저장 비교표로 바꿈
