## 결정

## 이유
요구사항이 금칙어(보류)와 이중화 기술 외에는 모두 확정돼 D-47의 조건(요구사항 정리 후)이 채워짐. 팀이 ERDCloud로 그리기로 해서 표로 정리하고, 조회용 인덱스는 쿼리가 정해진 뒤 추가하도록 메모로 분리

## 이전 내용 → 바꾼 이유
초기 요구사항 기준 ERD(테이블 20개)와 "나중에 갱신 예정" 목록 → 목록의 항목(이름·전화번호, 위임 요청, 블랙리스트, 제재 이력, 일부 공개, Refresh Token 등)을 모두 반영해 새로 작성
