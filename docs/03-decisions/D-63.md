# D-63 화면은 전부 Thymeleaf(서버가 HTML을 만듦)로, 일부 기능만 JS 요청

- 날짜: 2026-10-06
- 관련 항목: 7장 화면 방식, SEC-10
- 상태: 변경됨 → D-66

## 결정
화면은 전부 Thymeleaf(서버가 HTML을 만듦)로, 일부 기능만 JS 요청 (7장 화면 방식, SEC-10)

## 이유
기존 화면을 어차피 새로 만들어야 해서 섞어 쓸 이유가 없음. 한 방식으로 통일하면 규칙이 단순하고, SNS 미리보기(og 태그)·XSS 방어·CSRF 토큰을 서버에서 한 번에 처리함

## 이전 내용 → 바꾼 이유
추천안 "대부분 정적 + 글 상세만 Thymeleaf" → 새로 만드는 상황이라 전부 Thymeleaf로
