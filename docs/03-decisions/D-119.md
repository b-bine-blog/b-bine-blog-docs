# D-119 관리 블로그 상자의 삭제 버튼은 + 버튼을 눌렀을 때만 보인다

- 날짜: 2026-10-13
- 관련 항목: D-117 2번(관리 블로그 상자), BLG-06
- 상태: 확정

## 결정
1. 메인 위쪽 띠 오른쪽 "관리 블로그" 상자는 평소에 블로그 이름만 보여 주고, 각 줄의 "삭제" 버튼을 숨긴다.
2. 제목 옆 + 버튼을 누르면 고치는 상태가 된다. 각 줄에 "삭제"가 나오고, 칸이 남아 있으면 넣을 블로그 목록이 펼쳐진다. 3개가 다 찼으면 "최대 3개까지예요. 삭제로 빼고 넣으세요."라고 알린다. 그래서 + 버튼은 3개가 차도 잠기지 않는다.
3. 고치는 상태에서 빼거나 넣어도 고치는 상태는 이어진다. + 버튼을 다시 누르거나, 상자 바깥을 누르거나, Esc를 누르면 끝난다.

## 이유
사용자가 2026-10-13에 요청함: "+버튼 누를떄만 삭제 버튼이 나오겠금 하자 이유는 삭제버튼이 너무 신경쓰여서." 평소에 줄마다 삭제 버튼이 보이면 눈에 거슬린다.

## 이전 내용 → 바꾼 이유
- D-117 2번 "각 줄의 삭제"(항상 보임) → + 버튼을 눌렀을 때만 보임(사용자 요청).
- D-117 2번 "3개가 차면 +는 잠긴다" → 잠기지 않고 삭제 버튼을 보여 준다(빼야 넣을 수 있으므로).
