# D-92 글 본문은 최대 5,000자(공백·마크다운 기호 포함). DB 타입은 TEXT 유지

- 날짜: 2026-10-07
- 관련 항목: 6.6, ERD posts.content
- 상태: 확정

## 결정
글 본문은 최대 5,000자(공백·마크다운 기호 포함). DB 타입은 TEXT 유지 (6.6, ERD posts.content)

## 이유
보통 블로그 글은 1,000~3,000자라 1,000자는 사진 설명·마크다운 기호만 넣어도 부족하고, 500자는 더 짧음. 10,000자는 도배 글 하나가 너무 길어짐. TEXT(64KB)는 이모지만 써도 약 16,000자까지 들어가 5,000자에 충분하고, 제한을 바꿔도 DB를 고칠 필요가 없어 VARCHAR(5000) 대신 유지

## 이전 내용 → 바꾼 이유
최대 1,000자 → 길이가 부족해 5,000자로 늘림
