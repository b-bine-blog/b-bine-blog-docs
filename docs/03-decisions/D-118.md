# D-118 로그인·회원가입을 다른 화면으로 넘기지 않고 지금 화면 위 창으로 띄운다

- 날짜: 2026-10-13
- 관련 항목: USR-01(회원가입), USR-03(로그인), SEC-04(로그인 유지), D-66(정적 HTML), D-09(보안 헤더)
- 상태: 확정

## 결정
1. 머리 메뉴의 "로그인"·"회원가입"을 누르면 화면을 옮기지 않고, 지금 보던 화면 위에 창(`<dialog>`)을 띄워 그 안에 로그인·회원가입 화면을 보여 준다. 창 뒤로 원래 화면이 흐리게 보인다.
2. 창 안의 로그인 ↔ 회원가입, 이메일 찾기, 비밀번호 찾기 링크는 창 안에서 이어진다. 그 밖의 링크(약관 등)는 바깥 화면을 옮긴다.
3. 창 안에서 로그인에 성공하면 바깥 화면을 로그인한 상태로 새로 고친다(보던 화면 그대로). 닫기(×), 바깥 클릭, Esc로 창을 닫는다.
4. 로그인·회원가입 주소(`/login.html`, `/signup.html`)를 직접 열면 지금처럼 한 화면으로 보인다(로그인이 필요한 화면에서 넘어온 경우 등).
5. 화면은 같은 사이트 화면을 iframe으로 띄운다. 이를 위해 보안 헤더를 바꾼다.
   - `X-Frame-Options: DENY` → `SAMEORIGIN`
   - CSP `frame-src`에 `'self'` 추가, `frame-ancestors 'self'` 추가
   - 다른 사이트는 여전히 우리 화면을 iframe으로 품을 수 없다(클릭재킹 방지 유지).
6. 창도 메인 화면의 시간대 색 규칙(D-117)을 그대로 따른다. 창 안 화면은 바깥 화면과 같은 색(확인용 `?hour=`도 바깥 주소를 따름)이고, 창 뒤 어둠도 그 색으로 살짝 물든다(2026-10-13 사용자 요청).

## 이유
사용자가 2026-10-13에 요청함: "다른 사이트로 넘어가면 화면이 너무 남아서 메인화면에 창을 띄우면 내가 무엇을 회원가입하려는지 알수 있잖아." 다른 화면으로 넘어가면 보던 맥락이 사라지므로, 보던 화면 위에 창을 띄워 무엇에 가입·로그인하는지 보이게 한다.

## 이전 내용 → 바꾼 이유
- 로그인·회원가입: 별도 화면으로 이동 → 지금 화면 위 창(사용자 요청).
- 보안 헤더(D-09): 모든 iframe 금지 → 같은 사이트만 허용(창을 띄우기 위해).
