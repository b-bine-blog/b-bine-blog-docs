# D-83 만료된 Refresh Token은 매일 새벽 4시 배치에서 지운다

- 날짜: 2026-10-06
- 관련 항목: SEC-04, 4.5, BLG-09 폐쇄 처리
- 상태: 확정

## 결정
만료된 Refresh Token은 매일 새벽 4시 배치에서 지운다 (SEC-04, 4.5, BLG-09 폐쇄 처리)

## 이유
폐쇄 처리·완전 삭제를 하는 04:00 배치가 이미 있어 새 배치를 만들 필요가 없고, 이용자가 가장 적은 시간이라 DB 부담이 서비스에 영향을 주지 않음. ShedLock(SCL-03)으로 이중화 때도 한 번만 실행됨
