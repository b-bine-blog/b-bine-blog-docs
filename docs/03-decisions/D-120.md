# D-120 개별 블로그 첫 화면을 그림 칸과 이름 칸으로 나누고, 블로그 정보를 이름 칸에 합친다

- 날짜: 2026-10-13
- 관련 항목: BLG-03(블로그 첫 화면), BLG-05(대표 이미지·태그)
- 상태: 확정

## 결정
1. 개별 블로그 첫 화면(`/blog/{주소}`) 맨 위의 그림(대표 이미지, 없으면 색 띠)을 따로 한 칸으로 뺀다.
2. 그 아래 이름 칸에 블로그 이름, 소개, 블로그 정보(블로그장·멤버 수·공개 범위)를 한 줄짜리 표시로, 태그, 참여·구독 버튼을 함께 둔다.
3. 오른쪽 "블로그 정보" 칸은 없앤다. 글 목록은 화면 폭 전체를 쓴다.
4. 그림 칸은 크게(넓은 화면 280px, 좁은 화면 160px), 이름 칸은 작게 줄인다(이름 글자·여백·버튼을 작게). (2026-10-13 사용자 요청: "이부분을 더 크게 만들고 아래 일상블로그를 좀더 줄여볼래". 이유: 비율 조절).
5. 대표 이미지가 없거나 파일이 열리지 않으면 그림 칸을 통째로 빼고 이름 칸부터 보여 준다(예전에는 색 띠를 대신 보여 줌, 2026-10-13 사용자 요청: "이미지가 없다면 해당 칸을 뺴버리자"). 배경 이미지는 D-121.

## 이유
사용자가 2026-10-13에 요청함: "블로그 창이 너무 단순하고 정리를 해야할것같거든 일단 그림있는부분과 블로그이름있는 부분을 따로 뺴고 블로그 정보를 블로그이름 있는곳에 합처봐." 블로그 화면을 정리하는 첫 단계다.
