# D-117 메인 위쪽 띠를 소식 띠와 내 블로그로 바꾸고, 사이트 색을 시간대에 따라 바꾼다

- 날짜: 2026-10-13
- 관련 항목: D-116(위쪽 소식 띠), D-113(다크 모드), D-107(초록 색), BLG-06(내 블로그)
- 상태: 일부 변경됨 → D-119(삭제 버튼 표시)

## 결정
1. 메인 위쪽 띠의 제목("함께 쓰는 블로그")과 안내 문구를 화면에서 빼고, 소식 띠를 맨 위에 둔다. 제목은 화면 읽기용으로만 남긴다. 소식 띠 아래 점은 작게(6px) 해서 띠 바로 아래에 붙인다.
2. 띠 오른쪽 빈 곳에 "관리 블로그" 상자로 내가 운영(블로그장)·관리(부블로그장)하는 블로그 가운데 고른 것을 최대 3개 보여 준다. 고른 적이 없으면 만든 순서로 앞의 3개. 로그인하지 않았거나 운영·관리하는 블로그가 없으면 비워 둔다. 휴대폰처럼 좁은 화면에서는 숨긴다.
   - 각 줄의 "삭제"는 그 블로그를 이 칸에서만 뺀다(블로그는 그대로). 제목 옆 + 버튼은 운영·관리하는 블로그 목록을 펼쳐 하나를 골라 넣는다(목록은 최신순, 5개까지 보이고 그 뒤는 스크롤). 3개가 차면 +는 잠긴다.
   - 고른 목록은 그 브라우저에만 기억한다.
3. 내 블로그(`/api/me/blogs`, 내 정보의 내 블로그, 띠 오른쪽 상자)는 블로그가 만들어진 순서(오래된 것부터)로 보여 준다.
4. 띠 오른쪽 상자 제목을 누르면 내가 처음 만든 블로그로 간다. 만든 블로그가 없으면 내 정보의 내 블로그로 간다.
5. 머리 메뉴(다크 모드 옆)의 "내 블로그" 링크를 뺀다. 운영·참여하는 블로그 목록과 "블로그 만들기"는 내 정보 화면(`/me/index.html#blogs`)에 합친다. 예전 주소 `/me/blogs.html`은 그쪽으로 보낸다. 내 정보 화면은 카드(프로필, 기본 정보, 소개, 계정, 내 블로그)로 나눠 넓은 화면에서 두 칸으로 보여 준다. 운영하는 블로그(많아야 8개, 공개 3 + 비공개 5, BLG-10)와 참여한 블로그(제한 없음) 모두 5개씩 ‹ › 버튼으로 넘겨 본다. 블로그가 없을 때 프로필 메뉴의 "블로그 만들기"(D-109)는 그대로 둔다.
6. 사이트 전체 색(머리 메뉴, 위쪽 띠, 버튼, 카드, 배경)을 보는 사람 기기의 시각에 따라 바꾼다.
   - 아침(5~11시) 파랑, 점심(11~17시) 초록, 저녁(17~5시) 빨강. 각 시간대 한가운데(8시·14시·23시)에 가장 진하다.
   - 그 사이는 하루 내내 조금씩 넘어간다: 파랑 → 청록 → 초록 → 연두·주황 → 빨강 → 보라 → 파랑.
   - 1분마다 새 색을 정하고 그 1분 동안 CSS가 천천히 이어 준다. 밝기는 원래 초록과 같게 두고 색상만 바꾼다. 다크 모드도 같은 색상으로 어둡게 바뀐다.
   - 서버 작업은 없다(`theme.js`, `base.css`). 확인용으로 주소에 `?hour=14`를 붙이면 그 시각의 색을 보여 준다.

## 이유
사용자가 2026-10-13에 요청함: 제목·안내 문구를 빼고 소식 띠를 올리고 점을 작게 붙일 것, 빈 곳에 자신의 블로그를 띄우고 없으면 비워 둘 것, 내 블로그는 생성된 순서로 하고 누르면 내가 만든 블로그가 보이게 할 것, 상자 이름을 관리 블로그로 하고 삭제는 그 줄만 칸에서 빼고 +는 운영·관리하는 블로그 중 하나를 골라 넣게 할 것, 다크 모드 옆 내 블로그를 빼고 내 정보에서 관리하는 블로그와 블로그 추가를 합칠 것, 세로로 긴 내 정보 화면을 정리할 것, 참여한 블로그는 넘겨 볼 수 있게 할 것, 아침 파랑·점심 초록·저녁 빨강으로 전체 색이 자연스럽게 바뀔 것(시간 구간은 사용자가 정함).

## 이전 내용 → 바꾼 이유
- D-116 1번 "소개 문구 아래에 소식 한 줄" → 소개 문구를 빼고 소식 띠를 맨 위로(사용자 요청).
- 내 블로그 순서: 참여한 시각 최신순 → 블로그가 만들어진 순서(사용자 요청).
- 내 블로그 화면: 머리 메뉴의 별도 화면 → 내 정보 화면 안으로(사용자 요청).
- 사이트 색: 초록 고정(D-107) → 시간대에 따라 바뀌고, 점심 시간대에 원래 초록이 된다(사용자 요청).
