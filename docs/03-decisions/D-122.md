# D-122 "보기 10개" 개수 고르기를 다른 버튼과 어울리는 알약 모양으로

- 날짜: 2026-10-13
- 관련 항목: BRD-02(글 목록 개수), D-120(블로그 첫 화면)
- 상태: 확정

## 결정
1. 글 목록 등에서 한 번에 볼 개수를 고르는 칸("보기 10개")을 글자와 고르는 칸이 붙은 알약 모양 하나로 묶는다. 브라우저 기본 모양(위아래 화살표)을 쓰지 않고 작은 아래 화살표를 쓴다.
2. 같은 모양(`label.inline` 안의 고르기)을 쓰는 메인 화면·블로그 화면·알림 설정 화면에 함께 적용된다. 다크 모드도 같은 모양이다.

## 이유
사용자가 2026-10-13에 요청함: "이것도 너무 동떨어져 있는데 수정해볼래?" 고르는 칸이 기본 모양이라 화면의 다른 버튼과 따로 놀았다.
