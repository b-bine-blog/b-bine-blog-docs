# D-121 블로그장이 블로그 배경 이미지를 올릴 수 있다

- 날짜: 2026-10-13
- 관련 항목: BLG-05(블로그 정보 수정), BRD-05·6.3(이미지 규칙), D-75(FileStorage), D-120(블로그 첫 화면)
- 상태: 확정

## 결정
1. 개별 블로그 화면 뒤 배경은 기본(사이트 배경색)으로 두고, 블로그장(또는 정보 수정 권한이 있는 부블로그장)이 운영 화면에서 배경 이미지를 올리면 그 블로그 화면 뒤 전체에 깐다. 카드(이름 칸, 글 목록)는 그 위에 그대로 보인다.
2. 배경 이미지는 1장이고 대표 이미지와 같은 규칙(jpg·jpeg·png·gif·webp, 3MB, 검사·재인코딩, 30일 보관 후 삭제, 설정값 `blog.cover-image`)을 쓴다. 지우면 기본 배경으로 돌아간다. 파일이 열리지 않아도 기본 배경으로 보인다.
3. API: `PUT/DELETE /api/blogs/{blogId}/background-image`. 블로그 상세 응답에 `backgroundImageUrl`(없으면 null)을 더한다.
4. DB: `images.owner_type`에 `BLOG_BACKGROUND`를 더한다(`ck_images_owner_type` 제약 변경).

## 이유
사용자가 2026-10-13에 요청함: "뒤에 흰색부분도 기본으로 하고 이미지를 넣으면 적용이 가능한것으로 변경하자고 사용자 편의를 위해서." 결정 카드에서 "전체 배경"(카드 뒤 전체)을 골랐다.

## 이전 내용 → 바꾼 이유
- 블로그 화면 배경: 사이트 배경 고정 → 블로그장이 고른 이미지를 쓸 수 있음(사용자 요청).
