# D-109 메인 글 목록에 공지를 고정하고, 블로그가 있으면 메뉴에서 "블로그 만들기"를 뺀다

- 날짜: 2026-10-12
- 관련 항목: BRD-02(메인 피드), BRD(메인 공지), BLG-01, BLG-10, D-100 #18
- 상태: 확정

## 결정
1. 메인 화면 "글" 목록의 최신 탭 1페이지 맨 위에 최근 메인 공지를 고정해 보여 준다. "공지" 표시를 달고, 누르면 공지 글로 간다.
   - 개수는 설정값 `board.feed.pinned-notices=${BOARD_FEED_PINNED_NOTICES:3}`(0이면 보이지 않음, D-68).
   - 공지는 일반 글 목록(페이지 수, 한 페이지 개수)에 섞지 않고 `/api/feed` 응답의 `notices`로 따로 준다. 인기·구독·팔로우 탭과 2페이지부터는 빈 목록.
2. 운영하는 블로그가 하나라도 있으면 닉네임 메뉴에서 "블로그 만들기"를 뺀다. 블로그를 더 만들 때는 "내 블로그" 화면의 "블로그 만들기" 링크를 쓴다. 회원당 블로그 개수 한도(BLG-10, D-04)는 그대로다.

## 이유
사용자가 2026-10-12에 "공지사항도 글에도 나오게", "블로그를 만들면 메뉴의 블로그 만들기는 빼 달라"고 요청함. 메뉴를 숨기는 시점은 결정 카드에서 "하나 만들면"을 고름.
