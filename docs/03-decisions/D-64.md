# D-64 XSS는 서버에서 걸러냄(jsoup)

- 날짜: 2026-10-06
- 관련 항목: 7장 XSS 걸러내는 위치, SEC-06, SEC-12
- 상태: 확정

## 결정
XSS는 서버에서 걸러냄(jsoup). 화면에서는 사용자 입력을 이스케이프(th:text, textContent)하고 CSP로 한 번 더 막음 (7장 XSS 걸러내는 위치, SEC-06, SEC-12)

## 이유
서버에서 걸러야 API를 직접 부르는 공격도 막힘. 화면을 모두 서버에서 만들기로 해서(D-63) 마크다운 변환과 걸러내기를 서버 한 곳에서 할 수 있음. HttpOnly(D-53)는 토큰 탈취만 막고 XSS 자체는 못 막으므로 실행을 막는 방어가 따로 필요함
