# D-139 메인 화면에 끌어서 옮기는 내 정보 창을 띄운다

- 날짜: 2026-10-15
- 관련 항목: BRD-09, SOC-03, USR-01, D-118, D-134, D-137
- 상태: 확정

## 결정
1. 메인 화면 위에 내 정보 창을 띄운다. 제목 줄을 잡고 끌면 화면 안 어디로든 옮겨진다.
2. 창 오른쪽 위 − 를 누르면 네모난 프로필 사진만 남는다. 프로필 사진을 누르면 다시 펼쳐진다.
3. 위치와 접힘 상태는 그 브라우저에 기억한다. 휴대폰 화면에서는 접힌 채로 시작한다.
4. 회원에게 보이는 내용은 아래와 같다.

| 칸 | 내용 |
|---|---|
| 프로필 | 사진, 닉네임, 팔로워·팔로잉 수 |
| 내 블로그 | 블로그장·멤버인 블로그 바로가기 |
| 내 활동 | 작성글·작성댓글·스크랩·좋아요 개수(누르면 목록 창) |
| 알림 | 안 읽은 알림 수(누르면 알림 창) |

5. 로그인하지 않았으면 로그인·회원가입 버튼만 보인다(D-118처럼 지금 화면 위 창으로 연다).
6. 메인 관리자에게는 보이지 않는다(블로그 활동을 하지 않는 계정).

#### API
```
GET /api/me/summary
```

주의: 개수는 각 목록(/api/me/posts·comments·scraps·likes)과 같은 조건으로 센다.

## 이유
프로필 버튼을 원하는 곳에 둘 수 있게 하기 위해서다(2026-10-15 사용자).

## 이전 내용 → 바꾼 이유
- 내 정보와 내 활동은 오른쪽 위 계정 메뉴를 열어야 볼 수 있었다 → 메인 화면에 늘 떠 있고 원하는 곳으로 옮길 수 있다.
- DB 변경은 없다.
