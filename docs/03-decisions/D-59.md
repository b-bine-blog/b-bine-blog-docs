# D-59 공유 미리보기 대표 이미지는 글의 첫 이미지를 줄여서, 없으면 블로그 대표 이미지를 줄여서

- 날짜: 2026-10-06
- 관련 항목: BRD-07
- 상태: 확정

## 결정
공유 미리보기 대표 이미지는 글의 첫 이미지를 줄여서, 없으면 블로그 대표 이미지를 줄여서. 미리보기는 주소 → 제목 → 이미지 순서 (BRD-07)

## 이유
어떤 글이든 미리보기에 이미지가 들어가 눈에 띄고, 보여주는 순서를 정해 두어야 화면을 만들 때 기준이 명확함
