# D-107 서비스 이름은 "b-bine blog"

- 날짜: 2026-10-12
- 관련 항목: USR, BLG(화면 전체), D-66
- 상태: 확정

## 결정
서비스 이름을 "b-bine blog"로 정하고, 화면·메일에는 영어로 쓴다. 처음에는 "블로그"의 "블"과 combine(합치다)의 "바인"을 합친 "블바인"으로 시작했고, 영어 표기를 사용자가 "b-bine"으로 정했다. 여러 사람이 함께 블로그를 운영한다는 뜻이다.
- 화면 제목(`<title>`), 상단 로고 글자, 글 상세 og 태그의 사이트 이름, 인증 메일 제목·본문에 이 이름을 쓴다.
- 코드 패키지(`com.mainblog`), 저장소 이름, 문서 안의 "메인블로그"(가입·로그인을 하는 중심 사이트라는 뜻)는 그대로 둔다.
- 로고 글자는 무료 글꼴 Fredoka(SIL OFL), 화면 글꼴은 Pretendard(SIL OFL)를 서버에 같이 두고 쓴다.
- 색은 처음 초록(#218a56 계열)으로 되돌린다. 위 메뉴는 진한 초록, 첫 화면 띠는 초록 그라데이션.
- 화면의 나뭇잎 장식 그림은 모두 뺀다. 좋아요·뒤로 가기 같은 기능 아이콘(img/icon)은 남긴다.

## 이유
사용자가 2026-10-12에 이름을 "블바인 블로그"로 정하고 영어로 쓰기로 함. 영어 표기는 "b-bine blog"(소문자)로 확정. 그림은 빼고 색은 처음 초록으로 되돌리기로 함.
