# D-134 계정 메뉴에 작성글·작성댓글·스크랩, 글에 스크랩 버튼

- 날짜: 2026-10-14
- 관련 항목: BRD-02, REQ-063, REQ-064, D-112
- 상태: 확정

## 결정
1. 일반 회원의 계정 메뉴(내 정보·내 문의·로그아웃)에 "작성글", "작성댓글", "스크랩"을 더한다. 메인 관리자에게는 보이지 않는다.
2. 세 메뉴는 한 화면(/me/activity.html)의 탭으로 연다.
3. 블로그 글 화면의 "링크 복사" 옆에 스크랩 버튼을 둔다. 누르면 스크랩되고 "스크랩됨"으로 바뀐다. 다시 누르면 취소된다.
4. 한 회원이 한 글에 스크랩 하나만 둔다(post_scraps 유니크).
5. 공지와 메인 관리자는 스크랩하지 않는다.
6. 목록은 모두 본인 것만, 최신순이다. 스크랩은 스크랩한 순서 최신부터다.
7. 지운 글·댓글과 지금 볼 수 없게 된 글(비공개로 바뀐 블로그 등)은 목록에서 빠진다.
8. 글이 완전히 지워지면 그 글의 스크랩도 지운다.

## 이유
자신이 원하는 글이나 댓글을 주기적으로 봐야 하는 경우가 있다. 그 편의를 위해서다(2026-10-14 사용자).
