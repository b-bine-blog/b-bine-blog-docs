# D-135 메인 피드 팔로우 옆 + 로 태그 탭을 더한다

- 날짜: 2026-10-14
- 관련 항목: BRD-02, REQ-065, FR-023, FR-061~FR-064
- 상태: 확정

## 결정
1. 로그인한 회원은 메인 피드의 "팔로우" 탭 옆 + 버튼으로 원하는 태그 탭을 더한다.
2. 태그 탭은 계정에 저장한다(feed_tags). 어느 기기에서 로그인해도 같은 탭이 보인다. 본인만 본다.
3. 한 회원이 만들 수 있는 태그 탭 수는 설정값으로 둔다. 기본 5개다.
4. 태그 이름은 글 태그와 같은 규칙으로 정리한다(앞의 # 제거, 공백은 _, 영문 소문자).
5. 탭을 누르면 그 태그가 붙은 공개 블로그 글을 최신순 번호 페이지로 보여 준다. 10·20·30개씩 보기를 고를 수 있다.
6. 탭 옆 × 로 탭을 지운다.

#### 설정값
```
board.feed.tag-max-count=${BOARD_FEED_TAG_MAX_COUNT:5}
```

## 이유
사용자의 편의를 위해서다. 원하는 태그를 지정해 두면 사용자가 보고 싶은 글을 더 편하게 볼 수 있다(2026-10-14 사용자).

저장 위치는 사용자가 "계정에 저장"을 골랐다. 브라우저에 저장하면 다른 기기에서 탭이 비어 있기 때문이다.
