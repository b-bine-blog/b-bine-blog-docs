# D-85 신고 대상은 target_type + target_id로 가리키고, 신고 당시 대상 내용을 target_snapshot에 저장

- 날짜: 2026-10-06
- 관련 항목: SOC-06, 4.5, ERD reports
- 상태: 확정

## 결정
신고 대상은 target_type + target_id로 가리키고, 신고 당시 대상 내용을 target_snapshot에 저장 (SOC-06, 4.5, ERD reports)

## 이유
테이블이 단순하고 신고 대상 종류가 늘어도 ENUM 값만 추가하면 됨. 신고된 글·댓글은 30일 뒤 지워지지만 신고 기록은 1년 보관하므로, 내용을 같이 저장해야 분쟁 때 확인할 수 있음. 대상마다 FK 칸을 두는 방식은 칸이 늘 비고, 종류별 신고 테이블은 같은 코드가 반복돼 제외
