# D-115 메인 화면에서 블로그 둘러보기를 글 위 표지 카드 5개로 바꾼다

- 날짜: 2026-10-13
- 관련 항목: D-107(초록 디자인), BLG-02
- 상태: 확정

## 결정
1. 오른쪽 사이드바의 "블로그 만들기" 안내 상자를 뺀다. 블로그 만들기는 프로필 메뉴와 내 블로그 화면에 남는다.
2. 블로그 둘러보기를 글 피드 위 한 줄로 옮긴다. 블로그마다 표지 이미지(없으면 이름 첫 글자)를 크게 보여 주는 카드로, 5개만 보인다.
3. 좁은 화면에서는 카드를 옆으로 넘겨 본다.

## 이유
사용자가 2026-10-12~13에 안내 상자를 빼고, 블로그를 글 위에 블로그 화면처럼 각각 보여 주며 5개로 정해 달라고 요청함.
