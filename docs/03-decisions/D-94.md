# D-94 관리자 강제 폐쇄도 7일 유예, 철회는 블로그장만

- 날짜: 2026-10-07
- 관련 항목: ADM-02, BLG-09, 3.7
- 상태: 변경됨 → D-104

## 결정
메인 관리자의 블로그 강제 폐쇄도 누른 날짜 기준 7일 뒤 새벽 4시에 폐쇄하고, BLG-09와 같은 폐쇄 알림(즉시·3일 전·1일 전)을 보낸다. 폐쇄 철회는 블로그장만 할 수 있다 (ADM-02, BLG-09)

## 이유
블로그장 폐쇄와 같은 규칙이라 멤버가 글을 챙길 시간을 주고 처리 배치도 하나로 같음

## 이전 내용 → 바꾼 이유
강제 폐쇄가 즉시인지, 철회는 누가 하는지 정해지지 않았음.

> 2026-10-08: 관리자 강제 폐쇄의 철회는 메인 관리자만 하도록 바뀌었습니다(D-104). 7일 유예와 알림은 그대로입니다.

> 추론: 블로그장 권한 박탈 후 부블로그장이 없어 폐쇄되는 경우(ADM-07)는 블로그장이 없으므로 철회할 수 없는 것으로 읽었습니다. 다르면 고쳐 주세요.
