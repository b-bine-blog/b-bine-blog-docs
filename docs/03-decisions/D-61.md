# D-61 "로그인 유지" 체크박스: 체크 안 하면 브라우저를 닫거나 30분 무활동 시 로그아웃, 체크하면 14일 유지

- 날짜: 2026-10-06
- 관련 항목: SEC-04, USR-03
- 상태: 확정

## 결정
"로그인 유지" 체크박스: 체크 안 하면 브라우저를 닫거나 30분 무활동 시 로그아웃, 체크하면 14일 유지 (SEC-04, USR-03)

## 이유
화면을 나가면 로그아웃되는 것을 기본으로 해 공용 PC에서 로그인이 남지 않게 하고, 자기 기기에서는 체크해서 편하게 씀. 탭을 닫는 순간 로그아웃하는 방식은 새로고침·페이지 이동에도 로그아웃되고 모바일에서 잘 동작하지 않아 제외
