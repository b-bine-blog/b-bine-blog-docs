# D-103 메인 관리자·제재 세부 규칙 확정 (005 확인 항목)

- 날짜: 2026-10-08
- 관련 항목: ADM-01~07, 2장 권한표, 3.6, 3.7, SEC-03, SEC-09, SEC-11, SEC-13, 4.4, 4.5, D-17, D-30, D-44, D-60, D-85, D-90, D-93, D-94, D-95
- 상태: 확정

## 결정
005 명세의 확인 필요 항목을 21개 질문으로 묶어 아래처럼 정한다. 숫자는 설정값으로 둔다(D-68).

| # | 질문 | 결정 |
|---|---|---|
| 1 | 관리자는 회원과 다른 로그인 화면을 쓰나요? 관리자 계정은 누가 어떻게 만들고 회수하나요? | 로그인 화면은 회원과 같고(잠금·사람 확인 규칙도 같음, SEC-03·SEC-13), 관리자 페이지는 `/admin` 주소로 따로 두어 role = ADMIN만 들어감. 관리자 만들기 화면은 두지 않고, 서버 운영자가 블로그 활동이 없는 새 계정을 만들어 DB에서 role을 ADMIN으로 바꿈. 회수도 role을 USER로 되돌리며, 다음 요청부터 거부됨(FR-002) |
| 2 | 회원은 무엇으로 검색하나요? 상세 정보에 4.4 항목 말고 무엇을 넣나요? | 닉네임(일부만 맞아도 찾음)과 이메일(전체가 맞아야 찾음)로 검색. 이름·전화번호 검색은 1차에 없음. 상세에는 4.4 항목(가려서)과 가입일, 상태, 운영·참여 블로그, 블로그장 경고 이력(블로그별)을 넣음 |
| 3 | 탈퇴 후 30일 보관 중인 회원도 회원 검색에 나오나요? | 나오지 않음(4.5 "화면에 안 보임"). 신고·경고 같은 운영 기록에서는 "탈퇴한 회원"으로 표시 |
| 4 | 관리자 화면에서 이름도 기본으로 가리나요? | 가리지 않음. 가리는 형식은 이메일·전화번호에만 정해져 있고(4.4), 블로그장 화면에서도 이름은 그대로 보임. 명세의 인수 시나리오(이름·닉네임은 보임)와도 같음 |
| 5 | "전체 보기"를 누를 때 사유를 적나요? 한 번 누르면 어디까지 보이나요? | 사유 입력 없이 누른 관리자·시각·대상 회원만 남김(4.4대로). 그 회원 한 명의 상세 화면에서 그 한 번만 원래 값을 보여 주고, 다시 열면 다시 가림. 목록에는 "전체 보기"가 없음 |
| 6 | 블로그는 무엇으로 검색하나요? 폐쇄 예정·폐쇄된 블로그도 결과에 나오나요? | 이름·주소·블로그장 닉네임으로 검색. 공개 범위와 관계없이, 운영 중·폐쇄 예정·폐쇄됨(30일 보관 중)·숨김 블로그를 모두 보여 주고 상태를 표시함. 상태로 걸러 볼 수 있음 |
| 7 | 블로그를 숨기면 목록·검색·피드에서만 빠지나요, 들어가는 것도 막나요? 숨긴 동안 글을 쓸 수 있나요? 숨김을 풀 수 있나요? 블로그장·멤버에게 알리나요? | 목록·검색·피드에서 빼고(6.1), 멤버가 아닌 사람(비회원·구독자 포함)은 주소나 공유 링크로도 들어갈 수 없게 함. 블로그장·멤버는 평소처럼 보고 글을 씀. 관리자가 숨김을 풀 수 있음(풀 때도 활동 기록). 블로그장에게 "운영" 탭 알림(끌 수 없음)을 보내고 멤버에게는 보내지 않음 |
| 8 | 이미 폐쇄 예정인 블로그에 관리자가 "블로그 폐쇄"를 고르면 폐쇄 시각을 새로 잡나요? 그 뒤 블로그장이 철회하면 관리자 폐쇄도 철회되나요? | 기존 폐쇄 시각을 그대로 두고(늦추지 않음, 알림도 다시 보내지 않음) 폐쇄 사유만 관리자 폐쇄로 바꿔 기록. ~~철회는 D-94대로 블로그장이 할 수 있어 함께 철회됨. 다만 D-94가 관리자 폐쇄도 블로그장이 철회할 수 있게 되어 있어, 그 뜻이 맞는지도 함께 확인 부탁드립니다~~ 철회 부분은 변경됨 → D-104: 관리자 폐쇄로 바뀐 뒤에는 블로그장이 철회할 수 없고 메인 관리자만 철회함 |
| 9 | 관리자가 글을 숨길 때, 댓글을 숨기거나 지울 때도 작성자에게 알리나요? | 글을 숨기면 작성자에게 "운영" 탭 "내 글 숨겨짐" 알림(끌 수 없음, "내 글 삭제됨"과 같은 성격). 댓글 숨김·삭제는 알리지 않음(3.6 표에 없고, 블로그장의 댓글 삭제도 알리지 않음) |
| 10 | 숨긴 글을 작성자 본인이나 블로그장은 볼 수 있나요? 숨김을 풀 수 있나요? 숨김과 삭제는 30일 보관에서 어떻게 다른가요? | 작성자 본인에게만 "관리자가 숨긴 글" 표시와 함께 보이고, 블로그장을 포함한 다른 사람에게는 안 보임. 관리자가 숨김을 풀 수 있음. 숨김은 기간 없이 그대로 두고(30일 뒤 지우지 않음), 삭제만 30일 뒤 완전 삭제(4.5) |
| 11 | 관리자가 복구할 수 있는 것은 관리자·블로그장이 지운 것만인가요, 작성자 본인이 지운 것도인가요? 복구하면 작성자에게 알리나요? | 30일 안에 관리자·블로그장이 지운 글·댓글·사진만 복구(잘못된 삭제를 바로잡는 용도, 4.5). 작성자가 스스로 지운 것은 본인 뜻이라 복구하지 않음. 글을 복구하면 작성자에게 "운영" 탭 알림 |
| 12 | 블로그장에게 경고를 줄 때 사유를 적나요? 알림에 사유를 넣나요? | 사유 필수(1~500자, 설정값). 알림에 사유와 지금 경고 수(예: 3번 중 2번)를 넣음. 신고자는 넣지 않음 |
| 13 | 위임이나 자동 위임으로 새 블로그장이 되면 그 블로그의 경고 수를 이어받나요? | 이어받지 않고 0부터 시작. 경고는 그 블로그의 그 사람에게 준 것으로 셈(블로그별, D-95). 이전 블로그장이 나중에 다시 블로그장이 되면 1년 안의 자기 경고는 다시 셈 |
| 14 | 블로그장이 폐쇄 버튼을 눌러 폐쇄 예정인 블로그에서 권한을 박탈하면 어떻게 하나요? | 부블로그장이 있으면 자동 위임하고 폐쇄 예정은 그대로 둠(철회할지는 새 블로그장이 정함, D-94). 부블로그장이 없으면 기존 폐쇄 시각을 그대로 두고 새로 잡지 않음(알림도 다시 안 보냄). 지금 002 구현과 같음 |
| 15 | 블로그장이 보낸 위임 요청이 대기 중일 때 권한이 박탈되면 그 요청은 어떻게 되나요? | 자동 취소(요청한 사람이 더 이상 블로그장이 아님). 요청을 받은 멤버에게 "위임 요청이 취소되었습니다" 알림(끌 수 없음)을 보냄. 이때는 폐쇄 버튼 때와 달리 다른 알림이 가지 않을 수 있어서 |
| 16 | 자동 위임을 받을 부블로그장이 이미 공개 블로그를 3개 운영하고 있으면 어떻게 하나요? | 개수 제한을 적용하지 않고 그대로 넘김. 제한(BLG-10)은 새로 만드는 수에 대한 것이고, 일반 위임 수락에도 적용하지 않음. 넘긴 뒤에는 제한 아래로 내려갈 때까지 새 블로그를 만들 수 없음 |
| 17 | 박탈로 폐쇄할 때 "블로그장 권한 박탈로 인한 폐쇄 조치" 공지는 블로그 화면에 공지 글로 거나요, 알림 문구로만 알리나요? | 폐쇄 예정 알림 문구에 넣어 알림(지금 구현과 같음). 블로그장이 없어 블로그 공지 글은 따로 쓰지 않음 |
| 18 | 신고 처리 결과를 나중에 바꾸거나 다시 검토할 수 있나요? | 1차에는 바꿀 수 없음. 같은 대상에 새 신고가 오면 새로 처리함 |
| 19 | 운영 기록 1년은 언제부터 세나요? 1년 뒤에는 지우나요? 탈퇴 후 30일이 지나 개인정보가 지워진 회원의 기록에는 무엇이 남나요? | 기록이 생긴 날(조치·신고한 날)부터 1년, 1년 뒤 04:00 정리에서 지움(경고·정지 횟수에서 1년 지난 것을 빼는 D-95와 같은 기준). 영구 정지처럼 아직 효력이 있는 정지 기록은 풀릴 때까지 남김. 탈퇴 회원은 회원 번호만 남기고 "탈퇴한 회원"으로 표시. 신고 당시 내용(D-85)은 그대로 1년 보관 |
| 20 | 관리자 활동 기록은 누가 볼 수 있나요? 고치거나 지울 수 있나요? | 모든 메인 관리자가 볼 수 있음(관리자 등급은 두지 않음). 고치거나 지우는 기능은 두지 않고, 1년 지난 기록만 04:00 정리가 지움 |
| 21 | 통계에 탈퇴 회원, 폐쇄 예정·폐쇄된 블로그, 숨김·삭제된 글을 세나요? 일별 통계는 며칠까지 보여 주나요? | 회원 수는 탈퇴하지 않은 회원(관리자 계정 제외), 블로그 수는 운영 중·폐쇄 예정(숨김 포함, 폐쇄된 것 제외). 일별 가입·글 수는 그날 생긴 수를 그대로 셈(나중에 탈퇴·삭제돼도 셈). 일별 통계는 최근 30일(설정값, 30일 보관 기간 안이라 지운 것도 셀 수 있음) |
