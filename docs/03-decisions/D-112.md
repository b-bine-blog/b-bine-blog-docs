# D-112 시스템 문의를 만들고 관리자에게 알림으로 보낸다 (ADM-08 신설)

- 날짜: 2026-10-12
- 관련 항목: ADM-08(신설), SEC-13, D-22, D-68, D-79, D-10
- 상태: 확정

## 결정
1. 화면 아래 "개인정보 처리방침" 옆에 "시스템 문의" 링크를 두고 `/inquiry.html`에서 문의를 받는다.
2. 회원·비회원 모두 보낼 수 있다.
   - 회원: 로그인한 계정으로 보낸다. 답변은 알림(운영 탭, 끌 수 없음)과 "내 문의"로 본다.
   - 비회원: 답변 받을 이메일을 적고 사람 확인(Turnstile)을 통과해야 한다. 답변은 그 이메일로 메일을 보낸다.
3. 제목 30자, 내용·답변 2,000자, 같은 IP 하루 5건, 보관 1년. 모두 설정값(`inquiry.*`).
4. 문의가 오면 활동 중인 메인 관리자 모두에게 알림이 간다. 관리자 화면 "문의" 탭에서 대기·완료 목록과 대기 건수를 보고 답변한다.
5. 답변은 한 번만 달고 바꿀 수 없다. 관리자 활동 기록(INQUIRY_ANSWER)에 남는다.
6. 비회원 이메일은 관리자 화면에도 가려서 보인다. 메일은 서버가 보낸다.
7. 데이터: Crowfoot 요구사항 REQ-061, 표 `system_inquiries`(문서 버전 45). 명세는 `specs/006-system-inquiry/`.

## 이유
사용자가 2026-10-12에 "개인정보 있는 곳에 시스템 문의 올리는 것도 만들었으면 좋겠어. 관리자한테 해당 내용이 오게끔" 이라고 요청함.
누가 보낼 수 있는지는 결정 카드에서 "비회원도"를 골랐다. 나머지 숫자는 설계안을 보여 주고 "좋아 이렇게 진행하자"로 확인받았다.
