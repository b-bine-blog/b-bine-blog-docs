# D-93 신고 처리 범위: 블로그 안은 블로그장, 블로그장 대상과 메인 프로필 신고는 메인 관리자

- 날짜: 2026-10-07
- 관련 항목: SOC-06, ADM-04, BLG-13, 3.7
- 상태: 확정

## 결정
블로그 안의 회원·글·댓글 신고는 그 블로그의 블로그장이 처리한다. 블로그 자체나 블로그장에 대한 신고(블로그장이 자기 블로그에 쓴 글·댓글 포함)와 메인 프로필에서 한 회원 신고는 메인 관리자가 처리한다 (SOC-06, ADM-04)

## 이유
블로그장이 자기에 대한 신고를 직접 처리하면 안 되고, 메인 프로필은 특정 블로그에 속하지 않음

## 이전 내용 → 바꾼 이유
블로그장이 쓴 글·댓글 신고와 메인 프로필 신고를 누가 받는지 정해지지 않았음(D-45 보완)
