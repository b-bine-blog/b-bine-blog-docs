# D-111 버전 릴리스 노트 공지는 목록에서 "업데이트"로 표시한다

- 날짜: 2026-10-12
- 관련 항목: BRD(메인 공지), D-108, D-109
- 상태: 확정

## 결정
1. 제목이 `v1.02 …`처럼 버전(`v숫자.숫자`)으로 시작하는 메인 공지는 릴리스 노트(D-108)로 보고, 목록에서 "공지" 대신 "업데이트" 표시를 단다.
   - 메인 화면 "글" 목록 위에 고정한 공지(D-109): 버전 글은 "업데이트", 나머지는 "공지".
   - 공지사항 목록: 버전 글에만 "업데이트" 표시.
2. 데이터는 그대로다. 공지 종류 컬럼을 따로 두지 않고 제목으로 판단한다(D-108이 제목 형식을 정해 둠).

## 이유
사용자가 2026-10-12에 "업데이트 관련, 즉 v1.0 관련 글은 공지가 아니라 업데이트로 이름이 올라오게" 해 달라고 요청함.
