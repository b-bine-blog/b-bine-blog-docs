# D-137 좋아요한 글 목록과 메인 피드 "관심" 탭을 더한다

- 날짜: 2026-10-15
- 관련 항목: BRD-09, SOC, D-134, D-135
- 상태: 확정

## 결정
1. 계정 메뉴의 로그아웃 바로 위에 "좋아요한 글"을 둔다. 작성글처럼 지금 화면 위 창으로 열고, 창 안에도 "좋아요한 글" 탭을 둔다.
2. 좋아요한 글은 좋아요를 누른 순서 최신부터 보여 준다. 지워졌거나 이제 볼 수 없는 글은 빠진다.
3. 메인 피드 "인기" 옆에 "관심" 탭을 둔다. 로그인한 회원에게만 보인다.
4. 관심 탭 순서는 아래와 같다.
5. 관심 탭에는 쓴 지 3일 안의 글만 나온다. 좋아요가 100개를 넘을 때마다 3일씩 더 남는다.

#### 관심 탭 순서
| 순서 | 대상 | 정렬 |
|---|---|---|
| 1 | 내가 좋아요를 누른 구독 블로그의 글 | 좋아요를 많이 누른 블로그부터, 같으면 최신순 |
| 2 | 다른 구독 블로그의 글 | 최신순 |
| 3 | 팔로우한 회원의 글 | 최신순 |
| 4 | 그 밖의 공개 글 | 좋아요 많은 순, 같으면 최신순 |

#### 설정값
```
board.feed.interest-days=${BOARD_FEED_INTEREST_DAYS:3}
board.feed.interest-extend-likes=${BOARD_FEED_INTEREST_EXTEND_LIKES:100}
board.feed.interest-extend-days=${BOARD_FEED_INTEREST_EXTEND_DAYS:3}
```

#### API
```
GET /api/me/likes
GET /api/feed?tab=INTEREST
```

## 이유
유저가 관심 있어 할 만한 글이 있어야 사이트를 자주 보게 된다. 팔로우 기능이 있지만 처음부터 볼 사람을 찾기는 어렵다. 그래서 신규 사용자도 편하게 글을 찾도록 좋아요 확인과 관심 탭을 만든다(2026-10-15 사용자).

## 이전 내용 → 바꾼 이유
- BRD-09 메인 피드 탭: 최신·인기·구독·팔로우(+태그 탭, D-135) → "관심" 탭을 더함.
- 계정 메뉴: 작성글·작성댓글·스크랩(D-134) → "좋아요한 글"을 더함.
- DB 변경은 없다. 기존 post_likes·blog_subscriptions·follows를 쓴다.

주의: 3일 기간은 관심 탭에만 적용한다. "최신" 탭은 바꾸지 않았다.
