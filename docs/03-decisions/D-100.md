# D-100 게시판 세부 규칙 확정 (004 확인 항목)

- 날짜: 2026-10-08
- 관련 항목: BRD-01~11, BLG-01, BLG-07, BLG-11, USR-05, 2장 기능별 권한, 3.6, 6.1~6.3, 6.5~6.7, D-05, D-33, D-49, D-59, D-66, D-77, D-87
- 상태: 확정 (#15는 변경됨 → D-110, #8의 이름 "미분류"는 변경됨 → D-132)

## 결정
004 명세의 확인 필요 항목 21개를 아래처럼 정한다. 숫자는 설정값으로 둔다(D-68).

| # | 항목 | 결정 |
|---|---|---|
| 1 | 블로그를 떠난 사람의 글·댓글 | 떠난 뒤 그 블로그 글은 수정·삭제 모두 못 함(블로그장이 지울 수 있음). 댓글은 닉네임 그대로 둠 |
| 2 | 회원탈퇴한 사람의 댓글 | 내용은 남기고 작성자를 "탈퇴한 회원"으로 표시 |
| 3 | 답글까지 모두 지워진 "삭제된 댓글입니다" | 자리도 없앰 |
| 4 | 글에 쓰이지 않는 사진 | 하루 지난 뒤 04:00 처리에서 지움 표시, 파일은 30일 뒤 삭제 |
| 5 | 일부 공개 블로그 글의 공유 주소 | 글 주소에 블로그 공유 링크 값을 붙여 복사. 글 주소만으로는 볼 수 없음 |
| 6 | 일부 공개 글의 SNS 미리보기 | 공유 링크 값이 맞을 때만 제목·요약·사진. 아니면 사이트 기본 미리보기 |
| 7 | 목록 마우스 올림 사진 | 본문 첫 사진. 휴대폰은 목록 줄 오른쪽에 첫 사진을 작게 늘 보여 줌 |
| 8 | 카테고리 | 없이 쓸 수 있음(미분류). 지우면 글은 미분류로. 블로그당 최대 30개, 이름 1~30자 |
| 9 | 공유 링크로 들어온 회원의 댓글·좋아요 | 볼 수 있는 글이면 가능 |
| 10 | 대댓글에 답글 | 같은 1단계에 "@닉네임" 태그식으로 달림(D-87). 더 깊은 단계 없음 |
| 11 | 블로그장의 남의 댓글 삭제 | 블로그장과 글 관리 권한 부블로그장은 가능. 답글이 있으면 "삭제된 댓글입니다"로 남음 |
| 12 | 좋아요 요청 제한 | 회원당 1분에 30번 |
| 13 | 내 행동 알림, 다시 누른 좋아요 | 내 글에 내가 한 댓글·좋아요는 알리지 않음. 같은 사람이 같은 글에 다시 누른 좋아요는 다시 알리지 않음 |
| 14 | 미리보기 요약 | 마크다운 기호를 뺀 본문 앞 100자 |
| 15 | 미리보기 기본 이미지 | 사이트 기본 이미지 1장 (변경됨 → D-110: 글 화면 모양의 그림) |
| 16 | 검색 결과의 비공개 블로그 | 아예 빼고 개수에도 넣지 않음 |
| 17 | 최근 검색어 중복·비회원 | 같은 검색어는 맨 앞으로 옮김(중복 없음). 비회원은 제공하지 않음 |
| 18 | 피드 "새 글" | 최근 30일, 20개씩, "더 보기" 버튼 |
| 19 | 메인 공지 수정·삭제, 댓글·좋아요 | 메인 관리자면 누구나 수정·삭제. 댓글·좋아요 없음 |
| 20 | 비회원 조회 구분, 작성자 조회 | 브라우저 무작위 값 쿠키(1년)로 구분. 작성자 본인 조회는 세지 않음 |
| 21 | 봇 조회 | 같은 IP에서 1분에 글 60개 넘게 열거나 User-Agent에 bot·crawler·spider 등이 있으면 조회수에 넣지 않음(글은 정상으로 보임) |

팔로우 탭과 차단 규칙(SOC-01, SOC-05)은 003 범위라 003을 만들 때 붙인다. 004의 피드는 구독한 블로그의 새 글로 먼저 만든다.
