# 6. 세부 정책

기능 요구사항을 코드로 옮길 때 필요한 숫자와 규칙입니다. 상태가 확정인 항목은 그대로 구현하고, 보류인 항목은 팀에서 더 정해야 합니다. 팀에서 정한 것은 상태를 확정으로 바꾸고, 추천안과 다르게 정한 것은 추천안 칸을 고쳐 주세요.

## 6.1 검색

|항목|추천안|이유|상태|
|---|---|---|---|
|검색어 길이|2~20자|ngram이 2글자 단위라 1글자는 검색이 안 됨|확정|
|정렬|관련도순(기본), 최신순, 인기순 / 분류바(관련도, 최신, 인기). 인기순은 D-89 기준을 따른다(블로그는 멤버 수, 글은 좋아요 수). 값이 같으면 최신순으로 정렬한다.|검색은 관련도가 기본이고, 최신순은 선택|확정|
|결과에서 제외|비공개 블로그(공백으로 표시), 숨김·삭제 글, 내가 차단한 회원의 글|검색으로 비공개 내용이 새지 않게|확정|
|부가 기능|1차: 최근 검색어(본인만, 최대 10개, x 개별삭제 전체 삭제 기능)|자동완성은 검색 로그 저장과 집계가 따로 필요|확정|

## 6.2 SNS 공유

|항목|추천안|이유|상태|
|---|---|---|---|
|공유 수단|1차: 링크 복사. 2차: 카카오톡, X, 페이스북, 인스타, 텔레그램|링크 복사는 바로 되고, 카카오톡은 앱 키 등록이 필요|확정|
|카카오톡|Kakao JavaScript SDK로 공유 버튼 구현|국내 사용자가 가장 많이 쓰는 공유 경로|확정|
|미리보기|글 페이지에 Open Graph 태그(`og:title`, `og:description`, `og:image`)<br>url 최상단, 제목 상단후 닉네임까지, 이미지중단|없으면 카톡·X에서 제목과 썸네일이 안 뜸|확정|
|공유 수 집계|하지 않음|외부에서 실제로 공유됐는지는 알 수 없음|확정|

## 6.3 파일 업로드

|항목|추천안|이유|상태|
|---|---|---|---|
|허용 형식|jpg, jpeg, png, gif, webp|블로그에 필요한 사진 형식은 이것으로 충분|확정|
|제외 형식|svg, 동영상, 문서(pdf, hwp 등), 압축 파일|svg는 파일 안에 스크립트를 넣을 수 있어 XSS 위험|확정|
|글 이미지 크기|장당 3MB|휴대폰 원본 사진(3~5MB)이 그대로 올라감. 지금 프로젝트 설정도 5MB|확정|
|글 이미지 개수|글 하나에 최대 10장 (한 번에 보내는 용량 최대 10MB)|서버 저장 공간과 업로드 시간 제한|확정|
|프로필·블로그 대표 이미지|3MB, 1장|작게 표시되는 이미지라 큰 파일이 필요 없음|확정|
|검증 방법|확장자, MIME 타입(jpg, png, webp,gif,jpeg), 파일 시그니처(파일 앞부분 바이트)를 모두 확인|확장자만 바꾼 실행 파일을 막기 위해 (SEC-08)|확정|
|저장 방식|서버에는 UUID 이름으로 저장, 원래 이름은 DB에만|파일 이름 충돌과 경로 조작 공격 방지|확정|
|위치 정보|업로드할 때 EXIF(GPS 등) 제거|사진에 집 위치가 남아 있을 수 있음|확정|
|썸네일|목록용 썸네일을 따로 만들지 않고 원본을 CSS로 줄여 표시 (1차) (마우스 포인터를 글제목에 올렸을때 사진이 보이게)|구현이 간단함. 느리면 2차에 추가|확정|
|글 삭제 시|글을 정말 삭제하시겠습니까 확인버튼||확정|

## 6.4 태그

|항목|추천안|이유|상태|
|---|---|---|---|
|개수|글 하나에 최대 10개|태그 도배로 검색 결과가 오염되는 것 방지|확정|
|길이|1~20자|DB 컬럼 크기(30자) 안에서 여유|확정|
|허용 문자|한글, 영문, 숫자, `_`|특수문자·공백이 있으면 태그 링크가 깨짐|확정|
|입력 정리|앞의 `#`과 앞뒤 공백 자동 제거, 가운데 공백은 `_`로 바꿈|사용자가 `#`맛집처럼 입력해도 같은 태그가 되게|확정|
|중복 (한 글 안)|같은 태그를 여러 번 넣으면 하나로 합침|DB의 `uk_post_tags`가 중복을 막음|확정|
|중복 (대소문자)|영문은 소문자로 저장 (`Java` = `java`)|같은 태그가 두 개로 나뉘는 것 방지|확정|
|금칙어|두지 않음 (D-96)|팀 결정으로 제외|확정|

## 6.5 중복 규칙

|대상|추천안|이유|상태|
|---|---|---|---|
|이메일|중복 불가. 소문자로 바꿔 저장|`A@x.com`과 `a@x.com`은 같은 메일함|확정|
|닉네임|중복 불가. 2~12자, 한글·영문·숫자|프로필 주소와 멘션에 쓰임|확정|
|닉네임 예약어|관리자, `admin`, 운영자, 탈퇴한 회원 사용 불가|관리자 사칭 방지|확정|
|블로그 주소|중복 불가. 영문 소문자·숫자·`-`로 3~30자|URL에 들어가는 값|확정|
|블로그 주소 예약어|`main`, `admin`, `api`, `login`, `signup`, `search` 등 사용 불가|사이트 주소와 겹치면 페이지가 안 열림|확정|
|블로그 이름|중복 허용|블로그는 주소로 구분하므로 이름이 같아도 됨|확정|
|탈퇴 후 재가입|같은 이메일로 바로 재가입 가능, 예전 글과는 연결 안 됨|탈퇴 시 이메일을 비우므로(DB 설계)|확정|
|좋아요·팔로우·구독|한 번만. 다시 누르면 취소(트래픽 제한 걸기)|DB UNIQUE가 중복을 막음|확정|
|신고|같은 대상은 한 사람이 한 번만(2주뒤 신고가능)|한 사람이 신고를 부풀리는 것 방지|확정|
|참여 신청|대기 중인 신청이 있으면 다시 신청 불가. 거절되면 7일 뒤 재신청|블로그장에게 같은 신청이 쌓이는 것 방지|확정|

|항목|추천안|이유|상태|
|---|---|---|---|
|페이징 기본값|10개|처음 들어왔을 때 보여줄 개수|확정|
|제목|1~30자|목록 한 줄에 표시|확정|
|본문|최대 5,000자 (공백·마크다운 기호 포함). DB는 TEXT, 글자 수는 서버에서 검사|보통 블로그 글(1,000~3,000자)이 여유 있게 들어가고, 도배는 막음 (D-92)|확정|
|에디터|마크다운 (저장은 마크다운, 표시할 때 HTML로 바꾼 뒤 위험한 태그 제거)|WYSIWYG보다 XSS 막기가 쉽고, 구현이 가벼움 (SEC-06)|확정|
|수정 표시|수정한 글과 댓글에 "수정됨" 표시 댓글만|댓글이 달린 뒤 내용이 바뀜 수 있음|확정|
|임시저장|1차에는 브라우저에만 자동 저장|DB 없이 글 쓰다 날리는 것을 막음|확정|
|댓글 길이|1~500자|DB 컬럼 크기와 맞춤|확정|
|대댓글 깊이|1단계까지 (대댓글에는 답글 불가) 태그식으로 구현가능하면 해보기|화면이 오른쪽으로 계속 밀리지 않게|확정|
|댓글 삭제|답글이 있으면 "삭제된 댓글입니다"로 표시하고 답글은 남김|답글의 맥락이 사라지지 않게|확정|

## 6.7 회원·보안·운영 숫자

|항목|추천안|이유|상태|
|---|---|---|---|
|비밀번호|8~15자, 영문·숫자·특수문자를 모두 포함 대소문자 구분|SEC-02를 숫자로 확정|확정|
|로그인 잠금|5회 연속 실패 시 5분 잠금 또는 매크로 방지 기능 추가 생각|비밀번호 대입 공격을 늦춤 (SEC-03)|확정|
|사람 확인 (CAPTCHA)|로그인 3회 실패 후에 표시|모든 화면에 띄우면 불편하므로 봇이 노리는 곳에만|확정|
|로그인 유지|"로그인 유지" 체크박스. 체크 안 하면 브라우저를 닫거나 30분 활동이 없으면 로그아웃, 체크하면 14일 유지. 로그아웃 시 쿠키 삭제 (JWT, SEC-04)|공용 PC에서 로그인이 남는 것 방지 (SEC-04)|확정|
|비밀번호 재설정 인증번호|30분 뒤 만료, 1회용, 5번 틀리면 무효|메일이 유출돼도 쓸 수 있는 시간을 짧게 (SEC-05)|확정|
|조회수|비회원 회원 블로그장 블로그 글을 들어갈 시 카운트<br>같은 사람이 같은 날 같은 글을 보면 1번만 셈|새로고침이나 봇으로 조회수를 부풀리는 것 방지|확정|
|알림 보관|무슨 알림을 받을지 설정하는 체크박스 설정<br>회원, 블로그장 7일 또는 일괄 삭제 설정가능하게|알림 테이블이 계속 커지는 것 방지|확정|
