# 007 운영 규칙 안내

근거: D-114(2026-10-13 사용자 요청), D-68, 4.5. DB 변경 없음.

## 사용자 스토리

1. 누구나 화면 아래 "개인정보 처리방침" 옆 "운영 규칙"에서 지운 것이 언제 완전히 없어지는지, 무엇에 제한이 있는지 한곳에서 본다.

## 기능 요구사항

- FR-001 운영 규칙 화면(`/rules.html`)은 로그인 없이 볼 수 있다. [D-114]
- FR-002 화면에 나오는 숫자는 실제 설정값을 `GET /api/site-rules`로 받아 채운다. 화면에 숫자를 따로 적지 않는다. [D-68]
- FR-003 다루는 규칙: 삭제와 보관(4.5), 블로그 폐쇄(BLG-09), 블로그 만들기와 참여(BLG-10, 6.5, BLG-08, BLG-13), 글과 댓글(6.4, 6.6, FR-031), 로그인과 계정 보안(6.7, SEC-03, SEC-04, SEC-05), 신고와 제재(SOC-06, ADM-07, 4.5), 시스템 문의(ADM-08). [D-114]
- FR-004 비밀 값과 내부 운영값(요청 제한 창, 관리자 조회 한도 등)은 내려 주지 않는다. [D-114]

## 범위 밖

- 법률 검토를 거친 이용약관. 개인정보 처리방침 문구 자체.
