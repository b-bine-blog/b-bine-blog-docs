# 001 회원 기능 확인 필요 항목 (17개)

각 항목에 추천안을 적었습니다. (15번 만 14세 체크는 최신 문서의 D-91에서 "두지 않음"으로 이미 정해져 뺐습니다.) "추천대로"라고 답하시거나, 다르게 정할 번호만 알려 주세요.

"문서 근거"는 원본(`docs/01-requirements/요구사항분석서_원본_2026-10-07.md`)과 결정 기록(D-01~D-96)을 2026-10-07에 다시 확인한 결과입니다.
17개 모두 문서에 값이 정해져 있지 않습니다. 다만 일부는 비슷한 규칙이 있어 추천안을 그 규칙에 맞췄습니다.

- **없음**: 관련 내용이 문서에 없음
- **간접**: 직접 정하지는 않았지만 비슷한 규칙이 있어 추천안의 근거가 됨
- **틀만 있음**: 규칙은 있는데 숫자나 세부가 비어 있음

## 로그인·보안

| # | 질문 | 추천안 | 문서 근거 |
|---|---|---|---|
| 1 | 로그인 실패 문구가 "없는 이메일"과 "틀린 비밀번호"를 구별해도 되나? 없는 이메일로 5번 실패해도 같은 잠금 안내를 보이나? | 구별하지 않고 "이메일 또는 비밀번호가 맞지 않습니다"로 통일. 없는 이메일도 같은 안내 | 간접. 가입(USR-02, D-28)과 비밀번호 찾기(USR-06)는 가입 여부를 드러내지 않는다고 정함. 로그인 문구는 정하지 않음 |
| 2 | 로그인 실패 횟수를 언제 0으로 되돌리나? | 로그인 성공, 5분 잠금이 풀릴 때, 비밀번호 재설정 때 | 간접. SEC-03이 "5회 **연속** 실패"라 성공하면 끊김. USR-06에 "비밀번호가 바뀌면 로그인 잠금도 풀린다"가 있음 |
| 3 | 로그인에 IP별 요청 제한을 몇 번으로 하나? | 같은 IP에서 10분에 20번 | 틀만 있음. D-80이 "IP별 요청 제한"을 두기로 했지만 숫자가 없음. 참고로 이메일 찾기는 "같은 IP 10분에 5번"(USR-08) |
| 4 | 사람 확인(CAPTCHA)의 "3번 실패"는 무엇 기준인가? | 계정 기준 (잠금과 같은 실패 횟수) | 틀만 있음. SEC-13, 6.7은 "로그인 3회 실패 후 표시"만 정함 |
| 5 | "로그인 유지" 14일은 어떻게 세나? | 로그인한 때부터 14일 고정 | 틀만 있음. SEC-04, D-61은 "14일 유지"만 정함 |
| 6 | 글쓰기 중 로그인 연장 요청은 몇 분마다 보내나? | 입력이 있을 때 5분마다 | 틀만 있음. SEC-04, D-62가 "몇 분마다"라고만 씀 |
| 7 | Access Token 유효 시간은? | 15분 (Refresh Token으로 새로 받음) | 틀만 있음. SEC-04는 "짧게 유지되는 Access Token"이라고만 씀 |
| 8 | 비밀번호를 바꾼 그 기기는 로그인을 유지하나? | 유지(새 토큰 발급), 다른 기기만 로그아웃 | 간접. 재설정(USR-06)은 "다른 기기의 로그인은 모두 로그아웃". 내 정보에서 바꾸는 경우(USR-07)는 SEC-04에 "Refresh Token 폐기"만 있음 |

## 가입 입력값

| # | 질문 | 추천안 | 문서 근거 |
|---|---|---|---|
| 9 | 이메일 인증을 마친 뒤 가입을 끝내야 하는 시간은? | 30분 | 없음. 인증번호 만료 10분(USR-02)과 "마지막 단계에서 인증 완료를 다시 확인"(3.1 팀 결정)만 있음 |
| 10 | 비밀번호에 쓸 수 있는 특수문자는? | 키보드의 영문 특수문자 32종(`!@#$%^&*()` 등, 공백 제외) | 틀만 있음. SEC-02, 6.7은 "특수문자 포함"만 정함 |
| 11 | 닉네임 중복에서 영문 대소문자를 구분하나? | 구분하지 않음 (`Abc`와 `abc`는 같은 닉네임) | 없음. 6.5는 닉네임 "중복 불가, 2~12자, 한글·영문·숫자"만 정함. 이메일은 소문자로 바꿔 저장한다고 정함 |
| 12 | 예약어를 대소문자만 바꾸거나(`Admin`) 포함하면(`admin1`) 막나? | 둘 다 막음 | 틀만 있음. 6.5에 예약어 목록(관리자, admin, 운영자, 탈퇴한 회원)과 목적(관리자 사칭 방지)만 있음 |
| 13 | 전화번호 형식은? | 010으로 시작하는 11자리 숫자(휴대폰만) | 틀만 있음. USR-01은 "숫자만 저장, 1차는 중복 허용"만 정함 |
| 14 | 이름 입력 규칙은? | 2~20자, 한글·영문·공백 | 없음. USR-08에 "앞뒤 공백을 빼고 비교"만 있음 |
