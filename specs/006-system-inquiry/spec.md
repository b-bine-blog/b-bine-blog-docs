# 006 시스템 문의

근거: ADM-08(2026-10-12 신설), D-112. Crowfoot 요구사항 REQ-061, 표 `system_inquiries`.

## 사용자 스토리

1. 회원이나 비회원이 화면 아래 "개인정보 처리방침" 옆 "시스템 문의"에서 사이트 문제를 관리자에게 알린다.
2. 메인 관리자는 새 문의를 알림으로 받고, 관리자 화면 "문의" 탭에서 읽고 답변한다.
3. 회원은 답변을 알림과 "내 문의"에서 보고, 비회원은 적은 이메일로 받는다.

## 기능 요구사항

- FR-001 누구나 제목(1~30자)과 내용(1~2,000자)으로 문의를 보낸다. 글자 수는 설정값이다. [ADM-08, D-68]
- FR-002 로그인한 회원은 계정으로 보낸다. 이메일은 받지 않는다. [ADM-08]
- FR-003 비회원은 답변 받을 이메일을 적고 사람 확인(Turnstile)을 통과해야 보낸다. [ADM-08, SEC-13, D-79]
- FR-004 같은 IP는 하루 5건까지 보낸다(설정값). 넘으면 429 `RATE_LIMITED`. [ADM-08, D-68]
- FR-005 문의가 오면 활동 중인 메인 관리자 모두에게 운영 탭 알림(끌 수 없음)을 보낸다. 알림에 이메일은 넣지 않는다. [ADM-08, D-22]
- FR-006 관리자 문의함은 답변 대기(오래된 순)와 답변 완료(최근 답변 순)로 나눈다. 비회원 이메일은 가려서 준다. [ADM-08, D-22]
- FR-007 답변은 1~2,000자, 한 번만 달고 바꿀 수 없다. 이미 답변했으면 409 `INQUIRY_ALREADY_ANSWERED`. 관리자 활동 기록(INQUIRY_ANSWER)에 남는다. [ADM-08, ADM-06]
- FR-008 회원 문의의 답변은 알림(운영 탭, 끌 수 없음)으로, 비회원 문의의 답변은 커밋 뒤 메일로 보낸다. 메일을 못 보내도 답변은 저장된다. [ADM-08, D-10]
- FR-009 회원은 "내 문의"에서 자기 문의와 답변을 최근 순으로 10개씩 본다. [ADM-08]
- FR-010 문의는 받은 날부터 1년(설정값) 뒤 04:00 배치가 지운다. [ADM-08, 4.5]

## 범위 밖

- 문의에 첨부 파일, 답변 수정·추가 답변, 비회원의 답변 조회 화면.
